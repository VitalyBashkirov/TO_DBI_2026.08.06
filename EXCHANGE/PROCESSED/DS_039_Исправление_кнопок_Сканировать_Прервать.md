Контекст задачи
По результатам визуальной проверки GUI обнаружены две проблемы:

Проблема 1 — Кнопка «Сканировать» недоступна
На скриншоте кнопка «Сканировать» выглядит бледнее остальных — находится в состоянии disabled. Пользователь не может запустить сканирование сразу после запуска GUI.

Гипотеза: кнопка btn_scan осталась в state='disabled' после предыдущей операции (или в finally-блоке от DS_038 не сбрасывается состояние).

Проблема 2 — Кнопка «Прервать» имеет красный фон
Кнопка «⏹ Прервать» имеет красный фон (bg='#d9534f') всегда — даже когда неактивна. Это отвлекает и вводит в заблуждение.

Требование пользователя: ПОЛНОСТЬЮ убрать красный фон кнопки «Прервать». Кнопка должна быть стандартной — как «Очистить журнал» и «Копировать в буфер».

def on_scan_click(self):
    # DS 039: проверка PlpCheck-категорий (из DS 036)
    if not self._check_plpcheck_categories_before_action():
        return
    
    # DS 039: блокировка кнопки во время работы
    self.btn_scan.config(state='disabled')
    self.scan_running = True
    self.scan_aborted = False
    self.btn_abort.config(state='normal')
    
    try:
        # ... сканирование ...
        pass
    finally:
        # DS 039: ВСЕГДА сбрасываем состояние кнопок
        self.scan_running = False
        self.scan_aborted = False
        self.btn_scan.config(state='normal')       # ← ВАЖНО

Комментарий от меня
Задача простая, но есть нюанс:

Что делаем с кнопкой «Сканировать»
Наиболее вероятная причина — в finally-блоке on_scan_click() не сбрасывается state кнопки btn_scan в normal. Возможно:

Блокировка есть, разблокировка забыта.

Разблокировка есть, но не достигается (например, при исключении).

Разблокировка есть, но только в одной ветке (успех), а при прерывании не срабатывает.

Диагностика (grep) покажет точную причину.

Что делаем с кнопкой «Прервать»
Просто: удалить bg='#d9534f' и fg='white'. Кнопка станет стандартной.

Важно: убедиться, что нигде в коде не устанавливается bg для btn_abort (например, в on_abort_click()). Если есть — удалить.
