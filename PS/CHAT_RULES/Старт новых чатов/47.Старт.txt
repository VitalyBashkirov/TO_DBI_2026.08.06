## Сокращения GUI (правило 6as, полный текст — PS\46_Сокращения_GUI.txt)

Кнопки:
  К1 «1. Сканировать»
  К2 «2. Исправить код»
  К3 «3. В Ai»
  К4 «4. Из Ai»
  ГТ «Генерация тестовых .plp»

BOX «1. Пути и настройки сканирования»:
  ИКА — Исходный каталог (источник .plp)
  КР  — Каталог результатов (приёмник)
  Шаблон — объект GUI, сокращения не требует

BOX «3. Опции сканирования и исправления. Логирование» — флаги:
  МПК  — «Маркировка правок»: вставляет якоря-комментарии
  Применять — применять фактические правки (бывш. fix_only_found)
  ВТИК — «Верни только исправленный код без пояснений и маркеров изменений.
         Все пояснения, изменения, удаления журналируй» (= clean_output)
  НеАФ — ignore (не автофиксить, только лог)

Выпадающий список уровней логирования:
  УЛ  — Уровень логирования
  УЛМ — Уровень логирования. Минимальный
  УЛП — Уровень логирования. Подробный

Различения:
  ИКА (каталог-источник) != ИК (старое имя флага, см. МПК/Применять).
  ВТИК = clean_output (clean_output_var -> PLPlusFixer(clean_output=...)).
  PATCH_IN / PATCH_OUT — литералы в путях ИКА/КР, НЕ отдельные корневые каталоги.
  PATCH_CALC — рабочий/бэкап-каталог фиксера; создаётся на К1.
  PATCH_CALC/backups — бэкап перезаписываемых файлов (DS_155).

Приоритет флагов:
  ВТИК=on  -> МПК отменяется (якоря не ставятся); вернуть только исправленный код.
  НеАФ=on  -> правки НЕ применяются (сухой прогон); МПК может ставить якоря.

Формат якоря (МПК):
  -- YYYY.MM.DD HH:MI|<Правило>[xN][[Ai]]|Строка NN
  -- YYYY.MM.DD HH:MI|<Правило>[xN][[Ai]]|Строки NN-NN
  [xN]   — только если N>1 (число срабатываний).
  [[Ai]] — только если для правки использовался Ai.

## Матрица флагов (PS\46_Матрица_флагов.txt)

| МПК | ВТИК | НеАФ | Якоря | Правки | Возврат кода |
|-----|------|------|-------|--------|--------------|
| off | off  | off  | нет   | да     | полный файл |
| on  | off  | off  | да    | да     | полный файл с якорями |
| on  | off  | on   | да    | нет    | полный файл с якорями; правки только в лог (сухой прогон) |
| on  | on   | off  | нет   | да     | только исправленный код, без якорей (ВТИК перекрывает МПК) |
| off | on   | off  | нет   | да     | только исправленный код |
| off | off  | on   | нет   | нет    | без изменений, только лог |

6at (чат 46). Start-Transcript и объектный конвейер.
  В Start-Transcript надёжно попадает только host-вывод:
  Write-Host, Write-Output (строки), print из python, echo.
  Объектный конвейер (Get-Item | Select-Object, Get-Content без
  | Out-String, Format-Table) в транскрипт НЕ гарантированно попадает.
  РЕШЕНИЕ: ... | Out-String | Write-Host; либо Tee-Object; либо
  писать в отдельный .txt и читать Get-Content | Out-String | Write-Host.
  Для регламента 155 — ОБЯЗАТЕЛЬНЫЙ приём.
6at-1 (чат 46). Кириллица в многострочных литералах PS 5.1.
  Here-string @'...'@ с кириллицей при передаче через консоль может
  искажаться/обрываться. РЕШЕНИЕ: .py-скрипт (UTF-8 BOM) + python;
  либо [System.IO.File]::WriteAllText с UTF8Encoding($true).
6at-2 (чат 46). Проверка записи файлов в одном блоке (6ap).
  После записи — сразу: Get-Item ... | Out-String | Write-Host;
  Get-Content ... -TotalCount 5 -Encoding UTF8 | Out-String | Write-Host.
