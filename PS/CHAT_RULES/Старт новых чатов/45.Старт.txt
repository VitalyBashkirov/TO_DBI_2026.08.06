## ГЛАВНАЯ ТЕМА ЧАТА 45 — OQ-1 + OQ-2 (доработка кода, не тесты)

### OQ-1: _is_rule_selected — фильтрация по полному коду правила

**Файл:** SRC\analyzer\scanner.py, строка 728 (def _is_rule_selected).

**Проблема:**
- selected_rules с plpcheck.BAD_PREFIX не сужает набор plpcheck-правил — все plpcheck.* считаются выбранными.
- Причина: сравнение по префиксу plpcheck, а не по полному коду правила.
- Плюс multiline-правила (BAD_PREFIX/NOT_MENTIONED/WRONG_METHOD_SYNTAX/CODE_IN_COMMENT) выполняются всегда для .plp, независимо от selected_rules.

**Задача:**
- Сравнение по полному коду правила (plpcheck.BAD_PREFIX), а не по префиксу plpcheck.
- Фильтрация multiline-правил по selected_rules (сейчас _is_rule_selected вызывается в scan_file, но multiline проверки _check_plp_* его не учитывают).
- Обновить тесты: test_ds153d_scanner_selected_rules.py::test_selected_rule_does_not_narrow_plpcheck — после фикса CODE_IN_COMMENT НЕ должен попадать при selected_rules с plpcheck.BAD_PREFIX.

**Тесты:**
- SRC\tests\test_ds153d_scanner_selected_rules.py (6 тестов, обновить #6).
- Возможно, добавить новые тесты на фильтрацию multiline.

### OQ-2: close_ds.ps1 — пустой коммит (только bot.log)

**Файл:** tools\close_ds.ps1 (v2.1).

**Проблема:**
- close_ds.ps1 создаёт дублирующий коммит с тем же сообщением, если запустить его повторно, когда содержательных изменений уже нет (кроме EXCHANGE/bot.log).
- Пример: a50323f (AGENTS.md + DS_153_summary_report.md + bot.log) и dd4c933 (только bot.log).
- Причина: git add EXCHANGE/bot.log + git commit без проверки, есть ли в staged что-то, кроме bot.log.

**Задача:**
- В close_ds.ps1 добавить проверку: git diff --cached --quiet -- EXCHANGE/bot.log (или git diff --cached --name-only | Where-Object { $_ -ne "EXCHANGE/bot.log" }).
- Если только bot.log — коммит не делать (или делать с пометкой [botlog only]).
