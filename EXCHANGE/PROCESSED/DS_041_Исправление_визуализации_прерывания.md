Контекст задачи
После выполнения DS_040 (визуализация прерывания) обнаружены три дефекта, которые нужно исправить в одной задаче:

Дефект 1 — Индикатор НЕ жёлтый при прерывании
Симптом: пользователь нажимает «Прервать» до завершения процесса. Индикатор остаётся стандартного цвета (не жёлтый).

Ожидаемое: индикатор становится жёлтым (#FFA500) сразу при прерывании.

Дефект 2 — Заголовки в Markdown-отчёте не соответствуют прерванному сканированию
Симптом: в Markdown-отчёте (после прерывания) выводятся строки:

text
Всего проблем: 937
Уникальных проблем: 900
Всего файлов: 11
Требование пользователя: заменить «Всего» на «Обработано»:

text
Обработано проблем: 937
Уникальных проблем: 900
Обработано файлов: 11
Обоснование: при прерывании «Всего» вводит в заблуждение — на самом деле обработана только часть файлов. «Обработано» — точнее.

Уточнение: нужно уточнить у пользователя — менять ли заголовки только при прерывании или всегда. См. ЗАДАЧУ 3.

Дефект 3 — Длина индикатора отличается (обычное vs прерванное)
Симптом: длина закрашенной части индикатора при обычном сканировании и при прерванном — разная. Например:

Обычное сканирование: 30% → закрашено 30% длины.

Прерванное сканирование: 30% → закрашено 50% длины (или наоборот).

Ожидаемое: длина идентична — 30% закрашено и там, и там.

Возможные причины:

При прерывании value устанавливается несколько раз (например, value = percent + value = 100), и последнее значение перекрывает первое.

Или pb.stop() вызывается после прерывания и сбрасывает анимацию.

Или при прерывании используется другой расчёт процента (например, files_scanned / total, где total меньше, чем при обычном сканировании).

def on_abort_click(self):
    """DS 041: обработчик кнопки 'Прервать'."""
    if not self.scan_running:
        return

    # DS 041: перекрасить индикатор в жёлтый СРАЗУ
    try:
        self.pb.configure(style="Yellow.Horizontal.TProgressbar")
        self.pb.update_idletasks()   # ← принудительное обновление UI
    except Exception as e:
        print(f"[DS 041] Ошибка перекраски индикатора: {e}")

    self.scan_aborted = True
    self.log_message("[ПРЕРВАНО] Пользователь нажал «Прервать». Завершаем текущую операцию...", 'warning')
    self.btn_abort.config(state='disabled')
