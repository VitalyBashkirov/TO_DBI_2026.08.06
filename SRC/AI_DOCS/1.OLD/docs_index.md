## 🔧 Обработка PDF документов

### Статус извлечения текста

| Документ | Статус | Метод |

| тдс20240828.Требования для совместимости кода с DBI.pdf | ⏳ Ожидает обработки | pdfplumber / PyPDF2 |
| тклоик20240828.Требования к локальным объектам и к коду.pdf | ⏳ Ожидает обработки | pdfplumber / PyPDF2 |

### Установка зависимостей

```bash
pip install pdfplumber
# или
pip install PyPDF2
```

### Извлечение текста

```python
from fixer.rubricator_loader import RubricatorLoader

rubricator = RubricatorLoader()

# Извлечь текст из PDF
tds_text = rubricator.extract_pdf_text('DOC_TDS_PDF')
kloik_text = rubricator.extract_pdf_text('DOC_KLOIK_PDF')
```
