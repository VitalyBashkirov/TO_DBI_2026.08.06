### Вопрос 1 (критичный): tools\ — исключать полностью или частично?

**Решение: Исключить полностью.**

| Файл | Тип | Зачем CNT? | Альтернатива |
|------|-----|-----------|--------------|
| `_template_nightly.cmd` | Шаблон скрипта | "Как создать ночную задачу?" | Ответ в `DS_CNT_000_regulation.md` (раздел шаблоны) |
| `run_cnt_*.cmd` | Скрипт запуска | "Как запустить индексатор?" | Ответ в `DS_CNT_000_regulation.md` (раздел запуск) |
| `indexer\cli.py` | Код | "Как работает индексатор?" | Ответ в `DOCUMENTATION_ARM.md` |
| `indexer\config.py` | Код | "Какой rate limit?" | Ответ в `DS_CNT_000_regulation.md` |

**Обоснование:** Регламент `DS_CNT_000_regulation.md` уже содержит полную информацию по запуску, шаблонам, кодам возврата. .cmd/.py — не человекочитаемые документы, а исполняемый код. CNT ищет по смыслу — .cmd-файлы дают низкое качество эмбеддинга (много `REM`, `set`, `exit /b`).

### Вопрос 3 (критичный): Фильтр JSON/SQL > 50 KB — где реализовать?

**Решение: В `reader.py` (config.py).**

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| `.continueignore` | Просто | Нужно перечислять каждый файл; не масштабируется |
| `config.py` — `MAX_FILE_SIZE` | Автоматически для всех больших файлов | Может пропустить большой .md |
| `config.py` — фильтр по расширению + размеру | Точно: json/sql > 50 KB — исключить, md — всегда | Нужно добавить логику |

**Рекомендация:** Добавить в `config.py`:
```python
LARGE_FILE_LIMITS = {'.json': 50*1024, '.sql': 50*1024}
```
В `reader.py` проверять перед чтением.

**JSON в DATA\:** Только `4.RUBRICATOR_PROMPT v5.json` (494 KB) и `5.RUBRICATOR_PARSER_SQL v5.json` (133 KB). Оба > 50 KB. **Нет** JSON < 50 KB в `DATA\`. Оба исключить.

### Вопрос 7 (проверочный): Overlap 64 vs 32 — почему 64?

**Решение: Оставить 64. Не критично.**

| Overlap | Дубли (%) | Для 30 файлов (~90 чанков) | Влияние на поиск |
|---------|-----------|---------------------------|-------------------|
| 32 токенов (12.5%) | ~5 чанков с перекрытием | +5 чанков, +5 сек | Минимальное |
| 64 токенов (25%) | ~10 чанков с перекрытием | +10 чанков, +10 сек | Стандартная рекомендация nomic-embed-text |

**Обоснование:** 64 — стандарт для nomic-embed-text. При 30 файлах разница 5 секунд. Перекрывание предотвращает потерю предложений на границе чанка. Менять на 32 — экономия 5 секунд при риске потери контекста.
