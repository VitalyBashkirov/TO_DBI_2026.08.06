## Контекст задачи

После DS_049 в `bot.log` обнаружены **три проблемы**:

### 1. **Кодировка** — битые символы

```
[15:37:17] [+] Task moved to archive: F:\TO_DBI\EXCHANGE\PROCESSED\–Ґ–µ–Ї—Б—В–Њ–≤—Л–є –і–Њ–Ї—Г–Љ–µ–љ—В.txt
[15.09.2026 16:35:08] DS 049: Ќайдено задач в INBOX: 1
```

**Причина**: старая строка бота — в **cp1251**, новые строки Koda — в **UTF-8**. При чтении в **неправильной** кодировке — кракозябры.

### 2. **Транслит** — Koda пишет латиницей

```
[16:37:07] DS_997: Vypolneno. Test protokola DS_049. Fail perenesen v PROCESSED.
[16:38:13] DS_049: Vypolneno. Protokol zaversheniya Koda + process_inbox.py + AGENTS.md + DS_997 test. Fail perenesen v PROCESSED.
```

**Причина**: Koda избегает кириллицы в логах. **НО** — это выглядит **непрофессионально**. Особенно `Fail perenesen` (**вместо** `Файл перенесён`) — **ложное** слово «провал».

### 3. **Разный формат** — дата / описание

- Строка 1 — `[15:37:17]` (**только время**).
- Строки 2–4 — `[15.09.2026 16:35:08]` (**дата + время**).

**Цель DS_050**:
1. **Почистить** `bot.log` **вручную**.
2. **Настроить** Koda писать в `bot.log` **по-русски** в **UTF-8**.
3. **Проверить** `process_inbox.py` — **кодировка** **UTF-8**.

### ЗАДАЧА 2 — Настроить Koda писать в `bot.log` по-русски

**Файл**: `F:\TO_DBI\AGENTS.md`

**Действие**: Добавить раздел «Формат записей в bot.log»:

````markdown
## Формат записей в bot.log (DS_050)

### Обязательные требования

1. **Кодировка** — **UTF-8** (без BOM).
2. **Дата/время** — `[ДД.ММ.ГГГГ ЧЧ:ММ:СС]` (с **точкой** между ДД.ММ.ГГГГ).
3. **Формат** — `[ДД.ММ.ГГГГ ЧЧ:ММ:СС] DS XXX: <описание на русском>.`
4. **Кириллица** — **разрешена** и **обязательна**.

### Правильный пример

```
[15.09.2026 16:38:13] DS 049: Выполнено. Протокол завершения Koda. Файл перенесён в PROCESSED.
```

### НЕ использовать

- ❌ **Транслит** (`Vypolneno`, `Fail perenesen`, `Protokol zaversheniya`).
- ❌ **Смесь** латиницы и кириллицы.
- ❌ **Только время** без даты (`[16:38:13]`).
- ❌ **Английский язык** (`Task moved to archive`).
- ❌ **Слово** `Fail` (ложное).

### Случаи

| Событие | Формат записи |
|---------|---------------|
| **Задача выполнена** | `[ДД.ММ.ГГГГ ЧЧ:ММ:СС] DS XXX: Выполнено. <краткое описание>. Файл перенесён в PROCESSED.` |
| **Задача не завершена** (Koda задала вопрос) | `[ДД.ММ.ГГГГ ЧЧ:ММ:СС] DS XXX: Ожидание ответа пользователя. Файл остаётся в INBOX.` |
| **Ошибка** | `[ДД.ММ.ГГГГ ЧЧ:ММ:СС] DS XXX: Ошибка. <описание>. Файл остаётся в INBOX.` |

### Команда для записи

```powershell
Add-Content -Path "F:\TO_DBI\EXCHANGE\bot.log" -Value "[ДД.ММ.ГГГГ ЧЧ:ММ:СС] DS XXX: <описание>." -Encoding UTF8
```

**ВАЖНО**: параметр `-Encoding UTF8` — **обязателен**.
Прислать: фрагмент добавленного раздела.
