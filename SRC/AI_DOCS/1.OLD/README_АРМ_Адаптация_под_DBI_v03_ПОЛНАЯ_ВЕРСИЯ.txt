1. НАЗНАЧЕНИЕ
================================================================================

АРМ "Адаптация под DBI" v03 — автоматизированное рабочее место для миграции
PLPlus-кода с Oracle на PostgreSQL (2MCA DBI).

Основные возможности:
- Автоматический анализ PLPlus-кода на наличие проблемных конструкций
- Массовое исправление кода согласно требованиям документации
- Маркировка всех изменений с ссылками на пункты документации
- Логирование процесса по требованиям и файлам
- Сохранение структуры исходных каталогов

Поддерживаемые документы:
- v50 — Рекомендации по адаптации кода на PLPlus для работы с DBI (v50.1)
- тдс20240828 — Требования для совместимости кода с DBI
- тклоик20240828 — Требования к локальным объектам и к коду

7. ПРАВИЛА ОБРАБОТКИ
================================================================================

7.1. Автоматические исправления

v50.SQL.OUTERJOIN.п.1.1:
- Было: WHERE t1.id = t2.id(+)
- Стало: LEFT JOIN t2 ON t1.id = t2.id

v50.SQL.ROWNUM.п.1.2:
- Было: WHERE ROWNUM <= 10
- Стало: FETCH FIRST 10 ROWS ONLY

v50.SQL.DECODE.п.1.6.1:
- Было: DECODE(status, 'A', 'Active')
- Стало: CASE WHEN status = 'A' THEN 'Active' END

v50.STOR.DATE.п.2.2:
- Было: created_date DATE := SYSDATE;
- Стало: created_date DATE_TIME := SYSTEM.OP_DATE;

v50.PROC.WHENOTHERS.п.3.5:
- Было: WHEN OTHERS THEN NULL;
- Стало: WHEN OTHERS THEN ROLLBACK; RAISE;

7.2. Формат комментариев

```
-- {маркер} строки с {XXXX} по {YYYY}. {краткое описание}
--OLD {ГГГГ-ММ-ДД ЧЧ:ММ}:
-- {оригинальный код}
{исправленный код}
```

8. МАРКИРОВКА ИСПРАВЛЕНИЙ
================================================================================

8.1. Форматы маркеров

v50:
```
v50.КАТЕГОРИЯ.КОД_ИСПРАВЛЕНИЯ.п.X.X
Пример: v50.SQL.OUTERJOIN.п.1.1
```

тдс20240828:
```
тдс20240828.КАТЕГОРИЯ.КОД_ИСПРАВЛЕНИЯ.стр.X
Пример: тдс20240828.SQL.DML_JOIN.стр.1
```

тклоик20240828:
```
тклоик20240828.КАТЕГОРИЯ.КОД_ИСПРАВЛЕНИЯ.стр.X
Пример: тклоик20240828.LOCAL.PREFIX.стр.1
```

8.2. Категории

| Код | Описание |
|-----|----------|
| SQL | SQL/DML — соединения, ограничения, функции |
| STOR | Хранение — типы данных, таблицы, индексы |
| PROC | Процедурный код — пакеты, исключения |
| INT | Интеграции — Database Link, очереди |
| CACHE | Кэширование — уровни кэша |
| DEV | Общие требования — стиль, именование |
| LOCAL | Локальные объекты — префиксы, отчёты |
