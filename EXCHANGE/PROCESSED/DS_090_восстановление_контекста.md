# DS_090 — Восстановление контекста проекта

## Задача

Чат с DS обнулился. Нужно быстро восстановить понимание проекта, текущих задач и планов.

## Что сделать

1. Прочитай `AGENTS.md` в корне `F:\TO_DBI\` — это главный источник правил и структуры проекта.
2. Прочитай `README.md` в корне `F:\TO_DBI\` — описание проекта.
3. Прочитай `EXCHANGE\DS_CONTEXT.md` — контекст проекта.
4. Прочитай `EXCHANGE\DS_FILES.md` — карта файлов и функций.
5. Прочитай `EXCHANGE\DS_STANDARD.md` — стандарт оформления.
6. Посмотри последние коммиты: `git log --oneline -20` в `F:\TO_DBI`.
7. Посмотри статус: `git status --short` и `git branch --show-current` в `F:\TO_DBI`.
8. Проверь `PROJECT_STATUS\` на наличие статус-документов.

## Результат

Создай файл `F:\TO_DBI\EXCHANGE\OUTBOX\DS_090_восстановление_контекста.md` со следующим содержанием:

```markdown

**Дата**: YYYY-MM-DD HH:MM:SS
**Статус**: Выполнено

## Проект

Краткое описание проекта (1-2 абзаца).

## Ключевые файлы

- `SRC/gui_app.py` — что делает
- `SRC/analyzer/scanner.py` — что делает
- `SRC/rubricator_prompts.py` — что делает
- ... и т.д.

## Активные правила рубрикатора

- v53, тдс20240828, тклоик20240828, PlpCheck
- Отказанные: v50, v5.0.0

## Текущий статус

- Ветка: feature/dockerization
- Последние изменения: ...
- Незакоммиченные: ...

## Выполненные задачи (последние)

- DS_XXX — что сделано
- DS_YYY — что сделано

## Запланированные / текущие задачи

- ...

## Готовые команды для Koda

- `DS <файл>` — выполнить задание из INBOX
- `GIT` — коммит без push
- `PUSH` — pull --rebase + push
- `GP` — полный цикл GIT + PUSH
```

## После выполнения

- Перемести файл из `INBOX` в `PROCESSED`.
- Запиши в `bot.log`: `[ДД.ММ.ГГГГ ЧЧ:ММ:СС] DS 090: Выполнено. Контекст восстановлен. Файл перенесён в PROCESSED.`
