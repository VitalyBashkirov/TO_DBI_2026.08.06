## 4. Обоснование

**Принцип:** индексировать только то, что CNT может использовать для ответа на вопрос оператора/разработчика о регламентах, стандартах, правилах миграции, структуре проекта.

| Критерий | В индекс | Не в индекс |
|----------|----------|-------------|
| Человекочитаемый документ (md, txt) | Да | — |
| Машинная конфигурация (json > 50 KB, sql > 50 KB) | — | Нет (шум, раздувание) |
| Исходный код (.py, .sql, .ps1, .cmd) | — | Нет (не целевой поиск) |
| Бинарные форматы (docx, pdf, doc, xlsx) | — | Нет (не в TEXT_EXTENSIONS) |
| Транзитные данные (INBOX, OUTBOX, AI_IN, AI_OUT) | — | Нет (устаревают, дублируют) |
| Логи, temp, кеш | — | Нет (мусор) |
| Правило CNT (agents-short.md) | Да | — |

**Проверено:** «матрица доступа» не находит SEC_POLICY_AI.md при наличии .kilo\, SRC\, reports\, temp\ в индексе. Устранение мусора повышает точность.

## 6. Рекомендации по чанку

| Параметр | Рекомендация | Обоснование |
|----------|--------------|-------------|
| CHUNK_SIZE | **256 токенов** | Короткие запросы оператора. Меньший чанк — выше точность. |
| CHUNK_OVERLAP | **64 токена** | 25% — контекст не теряется на границах. |
| Время индексации | ~30 файлов × ~3 чанка = ~90 запросов = **~2 мин** | Rate limit 1 req/sec. |

**Почему не 512:** при 512 токенах чанк содержит 2–3 абзаца — конкретный термин теряет вес. Для документного поиска с короткими запросами 256 точнее. Для ~30 файлов разница во времени пренебрежима.

## 7. Порядок действий для переиндексации

1. **Обновить `tools\indexer\config.py`:**
   - `CHUNK_SIZE = 256`
   - `CHUNK_OVERLAP = 64`
   - Добавить в `EXCLUDE_SUBPATHS`: `EXCHANGE/INBOX`, `EXCHANGE/PROCESSED`
   - Фильтрация: `.json`/`.sql` > 50 KB — пропускать.

2. **Обновить `.continueignore`:**
   - Добавить: `SRC/`, `reports/`, `temp/`, `temp_fix/`, `RubricatorTemp/`, `logs_Deep/`, `.kilo/`, `Презентация/`, `Вопросы-ответы/`, `done/`, `tools/`, `EXCHANGE/INBOX/`, `EXCHANGE/PROCESSED/`.

3. **Удалить старый индекс:**
   ```
   Remove-Item "F:\TO_DBI\logs\indexer\*" -Recurse -Force
   ```

4. **Запустить переиндексацию:**
   ```
   F:\TO_DBI\.venv\Scripts\python.exe -m tools.indexer.cli index
   ```

5. **Проверить:**
   ```
   F:\TO_DBI\.venv\Scripts\python.exe -m tools.indexer.cli query "матрица доступа"
   ```

6. **Записать в `bot.log`:** результат.
