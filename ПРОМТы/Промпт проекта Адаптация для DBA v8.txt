Промпт для DS:
----
Рубрикатор представь в виде текстовых файлов-таблиц:
В первом RUBRICATOR_FILES.md,
перечень файлов с инструкциями, рекомендациями, регламентами, требованиями и т.п.
Поля таблицы:
-№;
-Признак действующий, устаревший (не используемый);
-Код из имен файлов, извлеченный из исходных документов:
 1. **v50** — `Рекомендации по адаптации кода на PLPlus для работы с DBI приложением v50.docx` (основной, 100+ правил)
 2. **тдс20240828** — `тдс20240828.Требования для совместимости кода с DBI.txt`
 3. **тклоик20240828** — `тклоик20240828.Требования к локальным объектам и к коду - Дополнительные регламенты разработчика - Confluence.txt`
 4. **лоб20220119** — `2022.01.19 Локальные объекты банка и DBI. Часть 1.txt`

-Полное имя файла (Путь+Имя файла).

Во втором RUBRICATOR_CATEGORIES.md,
группировка по категориям исправлений.
Поля таблицы:
- №;
- Код Категории:
 `SQL` — SQL/DML
 `STOR` — Хранение
 `PROC` — Процедурный код
 `INT` — Интеграции
 `CACHE` — Кэширование
 `DEV` — Общие требования разработки
 `LOCAL` — Локальные объекты и префиксы
 и другие.
- Описание категории;

В третьем RUBRICATOR_FIXES.md,
перечень требуемых исправлений:
Поля таблицы:
- №;
- Код исправления (Добавить Код файла.Код категории.Код исправления.Номер строк документации) 
  (Пример Кода исправления, если описание на одной строке v50.SQL.OUTERJOIN.стр.12,
  если описание в двух строках, то v50.SQL.DECODE.стр.15-16 
  и т.п.);
- Пункт(ы) документации (если есть);
- Строки документации (с..по) (пример стр.12 или стр.12-13)
- Короткое описание исправления;
- Подробное описание исправления.

Требования к АРМу:

1. Форма с переменными:
   - Каталог исходных: F:\TO_DBI\DATA\patch_RV\src\
     [V] Сканировать подкаталоги (шаблон: **\*.plp)
     [ ]7 Только указанный каталог
   - Каталог результатов: F:\TO_DBI\NEW_DATA\patch_RV_vXXXX (авто-итерация)
     [V] Только откорректированные файлы
     [ ] Все файлы по шаблону
     [V] Сохранять структуру исходных каталогов
   - Логи:
     [V] В разрезе требований
     [V] В разрезе исходного файла
   - Кнопка "Очистить логи"

2. Правила обработки:
   [V] Применять рекомендации (v50/тдс/тклоик) — выбрать ≥1
   [V] Перед изменённой строкой — маркировку
   [V] Следующая строка — закомментированный старый код
   [V] Исправленный код с комментарием (≤60 символов inline)
   [V] Обрабатывать .pck файл для списка объектов

3. Интерфейс:
   - Tooltips на всех кнопках
   - Блокировка кнопок при некорректных предыдущих действиях
   - Индикация прогресса выполнения
