ЗАДАЧА 4 — Форматирование последней категории (└ вместо ├)
Действие: Для красоты — последняя категория должна иметь префикс └ (а не ├). Реализовать через enumerate:

python
if code == 'PlpCheck' and is_on:
    active_categories = self.plpcheck_categories or []
    active_lower = [c.lower() for c in active_categories]
    total = len(PLPCHECK_CATEGORIES)

    for idx, (cat_code, cat_descr, cat_checks) in enumerate(PLPCHECK_CATEGORIES):
        cat_on = cat_code.lower() in active_lower
        cat_status = 'ВКЛ' if cat_on else 'ВЫКЛ'
