### Правило N13: при замене блока — сохранять ВСЕ строки

При замене многострочного блока на другой (например, if/elif/else → упрощённый) проверять, что все строки старого блока попали в новый. Особенно return, break, continue.
Инцидент чата 28: при замене 6 строк на 3 в _result_dir_has_pattern_files был потерян return any(...) → функция возвращала None → К3 не активировалась. Замаскировано debug-print.

### Правило N14: тесты через new — guard в методах

Если метод вызывается без init (тесты через new), проверять hasattr для переменных, создаваемых в init. Иначе AttributeError.
Инцидент чата 28: 3 теста упали после добавления _update_main_buttons в _finish_abortable_operation — guard через hasattr(self, 'source_dir_var').

## Уроки чата 28

### Урок AA: потеря return при замене блока

При @(...)-блоке в PS все строки должны быть точно воспроизведены. Пропуск return → функция возвращает None → логика ломается.

### Урок BB: debug-print маскирует потерю

Debug-print с _dbg_all временно вернул return — маскировал потерю. При удалении debug — потеря вскрылась. Вывод: debug-print не должен изменять логику, только логировать.

### Урок CC: settings.json не в git

Правки в settings.json не сохранятся в репозитории. В DS нужно явно указывать, что это локальная правка.
