### Правило N8: финал блока — зелёным, Stop-Transcript после

Каждый PS-блок, который выдаёт Автор DS, содержит:
1. Шапку (N1).
2. Очистку PS\ (N7) + Start-Transcript (N2).
3. Тело блока.
4. Финал: Write-Host "=== ГОТОВО ===" -ForegroundColor Green +
   Write-Host "Лог: $logPath" -ForegroundColor Green.
5. Stop-Transcript | Out-Null — ПОСЛЕ финального Write-Host.

Исключений для «мелких» блоков нет — любой блок логируется единообразно.

### Правило N9 (НОВОЕ, чат 26): избегать `} |` в PS 5.1

`foreach (...) { ... } | Out-Host` — ошибка EmptyPipeElement.
`... | ForEach-Object { ... } | Out-Host` — тоже может упасть, если `}`
и `|` на разных строках.

Надёжно:
    $out = foreach (...) { ... }
    $out | Out-Host

или

    $out = $collection | ForEach-Object { ... }
    $out | Out-Host

или

    $( ... ) | Out-Host
