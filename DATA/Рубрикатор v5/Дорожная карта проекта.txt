# ДОПОЛНИТЕЛЬНЫЕ ПРЕДЛОЖЕНИЯ К ПРЕДЛОЖЕНИЯМ KODA

## АНАЛИЗ ПРЕДЛОЖЕНИЙ KODA

KODA предложил **гибридную архитектуру**: детерминированный слой (Python, code_fixer.py) + LLM слой (KODA) для непокрытых случаев. Это правильный подход, но он **не учитывает возможность использования DeepSeek (DS) как основного AI-движка** в связке с KODA и VS Code.

---

## ПРЕДЛАГАЕМАЯ АРХИТЕКТУРА: DS + KODA + VS Code

## РАСПРЕДЕЛЕНИЕ ЗАДАЧ МЕЖДУ DS И KODA

| Задача | DS | KODA | Обоснование |
|--------|----|------|-------------|
| **Анализ кода по рубрикатору** | ✅ | ❌ | DS лучше понимает контекст и правила |
| **Сложные трансформации (CONNECT BY → WITH RECURSIVE)** | ✅ | ❌ | Требует глубокого понимания структуры запроса |
| **Замена DECODE на CASE** | ✅ | ❌ | Требует анализа вложенности и типов |
| **Анализ UDF в WHERE/GROUP BY/ORDER BY** | ✅ | ❌ | Требует определения пользовательских функций |
| **Генерация промптов для KODA** | ✅ | ❌ | DS составляет точные инструкции |
| **Обоснование изменений (журнал)** | ✅ | ❌ | DS лучше формулирует объяснения |
| **Выполнение конкретных замен по промпту** | ❌ | ✅ | KODA точно выполняет то, что ему сказано |
| **Массовые regex-замены** | ❌ | ❌ | Делает АРМ (Python) |
| **Переименование + обновление ссылок** | ❌ | ❌ | Делает АРМ (Python) |
| **Удаление неиспользуемых переменных** | ❌ | ❌ | Делает АРМ (Python) |

Создать библиотеку промптов для разных типов задач:

```python
# promtps.py
PROMPTS = {
    'analyze': """
        Проанализируй код по рубрикатору v5.0.1.

    """,
    'fix_prefix': """
        Исправь префиксы переменных по правилу PlpCheck.STYLE.PREFIX_COMBINATION.п.4.19.
        Формат: {назначение}{тип}{Смысл}
    """,
    'fix_class': """
        Исправь синтаксис класса по правилу PlpCheck.STYLE.WRONG_CLASS.п.4.12.
        class NAME → class ::[NAME]
    """,
    'fix_method': """
        Исправь вызов метода по правилу PlpCheck.STYLE.WRONG_METHOD.п.4.14.
        [class].method → ::[CLASS].[method]
    """,
    'generate_prompt_for_koda': """
        Сгенерируй промпт для KODA для исправления следующих проблем: {issues}
    """
}
```

## ПРЕИМУЩЕСТВА ПРЕДЛАГАЕМОЙ СХЕМЫ

| Преимущество | Описание |
|--------------|----------|
| **Разделение ответственности** | Каждый инструмент делает то, что умеет лучше всего |
| **Воспроизводимость** | Детерминированный слой дает стабильный результат |
| **Гибкость** | DS может адаптироваться к новым типам проблем |
| **Точность** | KODA точно выполняет конкретные инструкции |
| **Масштабируемость** | Можно добавлять новые правила без изменения кода |
| **Прозрачность** | Полный журнал изменений |

---

## РЕЗЮМЕ

1. **DS (DeepSeek)** — основной AI-движок для анализа, сложных правок, генерации промптов и обоснования изменений
2. **KODA** — исполнитель конкретных промптов от DS, выполняет точные замены
3. **VS Code** — среда разработки, редактор кода, просмотр diff
4. **АРМ (Python)** — управляет процессом, выполняет детерминированные правки, валидирует результат

**Ключевое отличие от предложения KODA:** в этой схеме DS играет роль "мозга", который анализирует, 
принимает решения и генерирует инструкции для KODA, а KODA — "рук", которые точно выполняют эти инструкции.
