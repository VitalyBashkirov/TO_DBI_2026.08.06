1. НАЗНАЧЕНИЕ
--------------------------------------------------------------------------------
АРМ предназначен для автоматизации миграции PLPlus-кода с Oracle на PostgreSQL
в рамках перехода АБС "ЦФТ-Банк" с Платформы 1 на Платформу 2MCA DBI.

2. УСТАНОВКА
--------------------------------------------------------------------------------
1. Установить Python 3.10+ (https://python.org)
2. Проверить наличие Tkinter: python -m tkinter
3. Скопировать проект в F:\TO_DBI (или другой каталог)

3. НАСТРОЙКА
--------------------------------------------------------------------------------
Файл: SRC\settings.json

Основные параметры:
- source_dir: Каталог с исходным кодом
- results_dir: Каталог для результатов
- logs_dir: Каталог для логов
- file_pattern: Шаблон файлов для сканирования (*.plp)

4. РАБОТА С АРМ
--------------------------------------------------------------------------------

4.1. Анализ кода
   1. Откройте PowerShell в каталоге SRC\analyzer
   2. Запустите: python scanner.py
   3. Результат: logs\scan_report_YYYYMMDD_HHMMSS.md

4.2. Исправление кода
   1. Откройте PowerShell в каталоге SRC\fixer
   2. Запустите: python code_fixer.py
   3. Результат: NEW_DATA\patch_WORK_vXXXX\

4.3. Проверка результатов
   1. Откройте исправленные файлы в VS Code
   2. Запустите Check DBI в CFT Platform IDE (Ctrl+D, A)

5. МАРКИРОВКА ИСПРАВЛЕНИЙ
--------------------------------------------------------------------------------
Все исправленные строки маркируются в формате:
-- v50 п.1.1
-- OLD: исходный код
исправленный код -- исправлено: описание

6. ЛОГИРОВАНИЕ
--------------------------------------------------------------------------------
- Лог по файлам: logs\fix_log_vXXXX.md
- Лог по требованиям: включает статистику по каждому пункту

7. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
--------------------------------------------------------------------------------
- v50.1.1 (Oracle outer join +): требует ручной доработки
- Сложные конструкции CONNECT BY: частичная автоматизация
