Проверки
========
PLSQL	- оптимизация приложения, работающего в 2L или режиме перевызова БД
JAVA	- оптимизация приложений, работающих на СП
DBI	- адаптация приложения под PostgreSQL
SQL	- проверки чистого SQL, т.е. фильтры параметров/переменных, условия переходов в представления
WEB	- проверки адаптации кода для ЦФТ Веб-Навигатора
STYLE	- префиксы, оформление кода
