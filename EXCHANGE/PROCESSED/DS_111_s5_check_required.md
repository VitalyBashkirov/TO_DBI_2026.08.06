**Дата:** 2026-10-07
**Автор:** DeepSeek
**Тип:** реализация (документация)
**Приоритет:** средний

## 1. Цель

Закрепить в `DS_STANDARD.md` и `AGENTS.md` правило: **§5 «Проверка» обязателен в каждом отчёте KODA**. Вывод команд (`Select-String`, BOM-check, `git log -1`, `pytest -q`) — в отчёт.

**Причина:** DS_109 и DS_110 сданы без §5-проверок (системная проблема двух сессий). В стандарте §3 нет раздела «Проверка», а `AGENTS.md` содержит формулировку «если в задаче не указано иное» — это позволяет KODA не выводить §5.

## 3. Ограничения

- Не трогать SRC.
- Только `EXCHANGE\DS_STANDARD.md` и `AGENTS.md`.
- Запись `.md` — только `[System.IO.File]::WriteAllText(..., UTF8Encoding($false))`.
- Чтение — только `Get-Content -Encoding UTF8`.
- Исторические отчёты не переименовывать.

## 4. Проверка (§5 — обязательно)

- `git log -1 --oneline`;
- `pytest -q` → 65 PASSED.
