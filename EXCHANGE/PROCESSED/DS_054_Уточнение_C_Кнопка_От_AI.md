## 1. Цель

Кнопка **«От AI»** должна быть **disabled**, если папка `F:\TO_DBI\EXCHANGE\AI_OUT` **пуста**. Иначе — пользователь нажимает впустую.

**Дополнительно:**
- При **появлении** файлов в `AI_OUT` — кнопка **включается**.
- При **исчезновении** (все обработаны) — **выключается**.

---

## 2. Что менять

| Файл | Что |
|------|-----|
| `SRC\gui_app.py` | Кнопка «От AI» — состояние `state=disabled/normal`; обновление при изменениях |

**Не менять:** `ai_exchange.py`, `scanner.py`, `code_fixer.py`, рубрикаторы.

---

## 3. Шаги

### 3.1. Проверка папки

**Функция:** проверяет, есть ли **хотя бы один файл** в `AI_OUT`.

```python
def _ai_out_has_files(self) -> bool:
    ai_out = Path("F:/TO_DBI/EXCHANGE/AI_OUT")
    if not ai_out.exists():
        return False
    return any(ai_out.iterdir())
```

### 3.2. Обновление состояния кнопки

- При **инициализации** GUI — вызвать `_update_ai_button_state()`.
- При **клике** «В AI» (отправка) — **перепроверить** (могли появиться ответы).
- При **клике** «От AI» (получение) — **перепроверить** после обработки.
- **Опционально** — периодическая проверка (каждые 5 сек) **или** кнопка «Обновить».

### 3.3. UI

- **Если `AI_OUT` пуст:** `button.config(state="disabled")` + тултип «В `AI_OUT` нет файлов».
- **Если не пуст:** `button.config(state="normal")` + тултип «Забрать ответы из `AI_OUT` (N файлов)».
