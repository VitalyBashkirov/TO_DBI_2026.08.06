## 1. Цель

По 19 NAME группы C (DS_071 §7.3 — многострочный transform) определить:

1. Какие **сводятся к однострочной замене** (regex с `replace_scope: "line"` / `"match"`).

4. Какие — **ignore** (детектор).

Разведка — **без правок исходников и рубрикаторов**. Цель — карта для DS_072c_Реализация.

4. Критерии классификации
Категория	Признак
C1. Однострочный regex	Замена в пределах строки (replace_scope: "line" / "match"). Пример: OUTER_JOIN — (true) → scalar subquery.
C2. Многострочный regex	Требует анализа ≥2 строк. Нужна доработка apply_fix (replace_scope: "multiline"). Пример: NOT_CLOSED_CURSOR — вставить close в begin.
C3. AI-фолбэк	Regex не даёт однозначной замены, нужен AI. Пример: ACCESS_STATIC — объявить doc ref + присвоить.
C4. Ignore (детектор)	Замена невозможна/нецелесообразна. Пример: SUBOPTIMAL_UNSELECTED_COL_USAGE — рефакторинг разработчика.

Приоритет	Критерий

Средний	C2 — после доработки движка; C3 — AI
Низкий	C4 — ignore
