### Правило N10 (НОВОЕ, чат 27): .Replace на строке, не присваивание целиком

При замене строки в массиве ВСЕГДА использовать:
    $lines[$i] = $lines[$i].Replace($old, $new)
НЕ:
    $lines[$i] = $new   # ← теряются отступы
Инцидент: блок A, потерян отступ L991, IndentationError.

### Правило N11 (НОВОЕ, чат 27): git rm -f для файлов с локальными модификациями

`git rm` без `-f` отказывается удалять modified-файлы. Использовать `git rm -f`
(если файл всё равно удаляется) или `git checkout` + `git rm`.

### Правило N12 (НОВОЕ, чат 27): скрипты `if __name__ == '__main__'` не в pytest

Файлы вида `test_dsXXX_*.py` с `if __name__ == '__main__': main()` и `sys.exit(...)`
НЕ собираются pytest. Для регресса их надо запускать вручную:
    python SRC\tests\test_ds133_buttons_state.py
Это соответствует стилю DS_087. Перевод в pytest — отдельная задача.
