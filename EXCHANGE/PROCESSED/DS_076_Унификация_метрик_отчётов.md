## 1. Цель

Устранить путаницу «Всего файлов» — сейчас **одна метка** в двух отчётах означает **разные величины**:

| Отчёт | Метка | Значение | Семантика |
|-------|-------|----------|-----------|
| `scan_report_*` | `Всего файлов` | **166** | Файлов **с issues** |
| `scan_VVVVVV_*` | `Всего файлов` | **71** | Файлов **с dry-run changes** |
| — | — | 171 | Все `.plp` (фактически) |

**Решение:** в **обоих** отчётах — **три метрики**:
Всего файлов: 171 (все просканированные)
Файлов с проблемами: 166 (есть issues)
Файлов с изменениями: 71 (dry-run дал changes)

## 4. Детали реализации

### 4.1. Формат вывода (единый)

**`scan_report_*` — заголовок статистики:**
======================================================================
ИТОГОВАЯ СТАТИСТИКА
======================================================================
Всего проблем: 15478
Прогноз исправлений: 608
Исправлено: 0
В AI: 14418
Всего файлов: 171
Файлов с проблемами: 166
Файлов с изменениями: 71

text

**`scan_VVVVVV_*` — то же.**

### 4.2. Как считать

| Метрика | Источник |
|---------|----------|
| `Всего файлов` | `total_files = len(all_files)` после `_should_exclude` |
| `Файлов с проблемами` | `len(issues_by_file)` — число уникальных `file_path` в `self.issues` |
| `Файлов с изменениями` | `len([sf for sf in sim_files if sf['changes']])` — для `scan_VVVVVV_*`; для `scan_report_*` = `forecast`-файлы |

**Важно:** для `scan_report_*` — «Файлов с изменениями» = **число файлов, где прогноз дал хоть один change** (пересекается с логикой `_forecast_and_ai_counts`).

### 4.3. Совместимость

- Если **прерывание** (`is_aborted`): `Всего файлов` → `Обработано файлов` (как сейчас, `scanner.py:2282`).
- Если **старые отчёты** — не ломаются (новые строки — дополнительные).

### 4.4. Побочный фикс (опционально)

**`.v????`** — мёртвый паттерн (literal, не маска). **Убрать** из `exclude_patterns` (4 места в активных файлах):
- `SRC\gui_app.py:2505`, `SRC\gui_app.py:2970`
- `SRC\fixer\code_fixer.py:2082`

**Причина:** никогда не срабатывает → бесполезен.

**Проверка:** `Select-String -Path "F:\TO_DBI\SRC\*.py" -Pattern "\.v\?\?\?\?" -Encoding UTF8`
