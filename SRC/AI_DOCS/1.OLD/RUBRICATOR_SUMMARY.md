## 📝 Формат маркировки (по рубрикатору v03)

```plp
-- тдс20240828.п.1 строки с 25 по 42. SYSDATE -> SYSTEM.OP_DATE
--OLD 2026-04-15 10:30:
-- created := SYSDATE;
created := SYSTEM.OP_DATE;
```

**Компоненты:**
1. **Маркер** — `тдс20240828.п.1` (из PDF документа)
2. **Ссылка** — `строки с 25 по 42` (диапазон в txt/pdf)
3. **Описание** — `SYSDATE -> SYSTEM.OP_DATE` (≤120 символов)
4. **OLD** — `2026-04-15 10:30` (без секунд)
5. **Оригинал** — закомментированная строка
6. **Новый код** — исправленная строка

## 🚀 Как использовать

### 1. Просмотреть рубрикатор

```bash
cd F:\TO_DBI\SRC\fixer
python rubricator_loader.py
```

### 2. Извлечь текст из PDF (v03)

```bash
# Установите зависимости
pip install pdfplumber

# Извлеките текст
python -c "from fixer.rubricator_loader import RubricatorLoader; r = RubricatorLoader(); print(r.extract_pdf_text('DOC_TDS_PDF')[:500])"
```

### 3. Отредактировать в Excel

```bash
# Откройте rubricator_markers.xlsx
# Внесите изменения
# Сохраните
# Запустите create_excel_rubricator.py для обновления JSON
```

### 4. Запустить исправление

```bash
cd F:\TO_DBI\SRC\fixer
python code_fixer.py
# Автоматически загрузит актуальные правила из рубрикатора
```

### 5. Добавить новое правило

1. Откройте `rubricator_markers.json`
2. Добавьте запись в `markers`
3. Установите `status: draft`
4. Протестируйте
5. Переведите в `active`
