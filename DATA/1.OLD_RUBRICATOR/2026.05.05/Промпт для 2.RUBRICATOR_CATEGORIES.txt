Сформировать файл "2.RUBRICATOR_CATEGORIES.md" - # Рубрикатор: категории исправлений

Просмотреть каталог "F:\TO_DBI\DATA\CFT Platform IDE Documentation" без просмотра подкаталогов
в следующей очередности:
  имя файла,
  расширение .docx
  расширение .doc
  расширение .txt
  расширение .pdf
Если есть файлы с одинаковым именемя, в обработку брать первый файл. Со следующим по очереди файлом не работать.

В качестве примера работаем со следующим списком:
F:\TO_DBI\DATA\CFT Platform IDE Documentation\Рекомендации по адаптации кода на PLPlus для работы с DBI приложением v50.docx
F:\TO_DBI\DATA\CFT Platform IDE Documentation\Требования для совместимости кода с DBI.txt
F:\TO_DBI\DATA\CFT Platform IDE Documentation\Требования к локальным объектам и к коду - Дополнительные регламенты разработчика - Confluence.txt

На основании результатов сканирования создать текстовую таблицу 
1. Структура таблицы
|Колонка  |Ширина     |Содержимое 
|---------|-----------|--------------------------------------------
|N        |2          |порядковый номер (1, 2, 3...)
|Категория|11         |символ "+" или "-" (по умолчанию "+") 
|Код(ы) файлов|15     |коды файлов из "1.RUBRICATOR_FILES.md"
|Описание категории|99|Описание

2. Вторая строка таблицы между заголовком и строками
Между символами-разделителями `|` формировать содержимое из символов `-`
Количество символов должно соответствовать ширине колонки.
