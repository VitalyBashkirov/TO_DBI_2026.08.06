# DS 028: Расширенный формат отчёта с колонкой ПЛАН

## Задача
Дополнить формат отчёта:
1. Добавить колонку `{ПЛАН}` с вычисляемым исправлением
2. Поддерживать диапазон строк (если исправление затрагивает несколько строк)
3. Показывать исправляемые и новые строки под записью
4. **НЕ УДАЛЯТЬ** рабочий код — только исправлять

## Правила формирования ПЛАНА

| Тип правила | ПЛАН | Действие |
|-------------|------|----------|
| `bad_prefix` | `Переименовать в "{имя}"` | Исправить префикс |
| `not_mentioned` | `Удалить объявление` | Закомментировать/удалить |
| `code_in_comment` | `Удалить закомментированный код` | Удалить ТОЛЬКО закомментированные строки |
| `wrong_method_syntax` | `Исправить синтаксис` | Исправить |
| `prefix_type_in_var_name` | `Добавить префикс "{префикс}"` | Исправить |
| `syntax_error` | `Исправить синтаксическую ошибку` | Исправить |
| `pure_sql_dblink` | `Заменить на прикладную таблицу` | Заменить |
| `pure_udf` | `Вынести UDF в процедурный код` | Переписать |
| `outer_join` | `Заменить на ANSI JOIN` | Переписать |
| `rownum` | `Заменить на FETCH` | Переписать |

## Важные правила для НОВЫХ СТРОК

### 1. Не удалять рабочий код
```python
def _apply_fix(self, issue_type: str, original_code: str) -> str:
    """Применение исправления к строке"""
    # Если строка закомментирована и это code_in_comment — удаляем
    if 'code_in_comment' in issue_type and original_code.strip().startswith('--'):
        return "-- (удалено)"
    
    # Если это не рабочий код (пустая строка или только комментарий)
    if not original_code.strip() or original_code.strip().startswith('--'):
        return original_code
    
    # Для рабочих строк — применяем исправление
    if 'bad_prefix' in issue_type:
        return self._fix_bad_prefix(original_code)
    
    if 'wrong_method_syntax' in issue_type:
        return self._fix_method_syntax(original_code)
    
    if 'prefix_type_in_var_name' in issue_type:
        return self._fix_prefix_type(original_code)
    
    # По умолчанию — оставляем как есть
    return original_code
2. Для code_in_comment

def _fix_code_in_comment(self, original_code: str) -> str:
    """Исправление закомментированного кода"""
    if original_code.strip().startswith('--'):
        # Удаляем закомментированный код
        return "-- (удалено)"
    # Если строка не закомментирована — оставляем
    return original_code
3. Для not_mentioned
python
def _fix_not_mentioned(self, original_code: str) -> str:
    """Исправление неиспользуемой переменной"""
    if original_code.strip() and not original_code.strip().startswith('--'):
        # Закомментируем объявление
        return "-- " + original_code
    return original_code
