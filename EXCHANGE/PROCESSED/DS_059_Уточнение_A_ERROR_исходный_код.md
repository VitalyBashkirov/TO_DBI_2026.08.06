## 1. Цель

В логах `scan_report_*` колонка **ERROR** должна содержать **исходный проблемный фрагмент кода** (то, что нужно изменить), а не только общее описание.

**Колонка PLAN** — содержит **действие** (что сделать).

**Формат (для всех правил):**
```
<описание проблемы>: "<исходный_фрагмент>"
```

## 3. Шаги

### 3.1. Формат `ERROR`

**Для PlpCheck (пример `bad_prefix`):**

**Было:**
```
ERROR: Не корректный префикс, пожалуйста переименуйте в "v_iDp"
PLAN:  Переименовать в "v_iDp"
```

**Стало:**
```
ERROR: Не корректный префикс, пожалуйста переименуйте "Dp"
PLAN:  Переименовать в "v_iDp"
```

- В `ERROR` — **исходный** идентификатор (`"Dp"`).
- В `PLAN` — **целевой** (`"v_iDp"`).

### 3.2. Для v53 (пример `spec_chars`)

**Было:**
```
ERROR: Спецсимволы в именах
PLAN:  Исправить по описанию
```

**Стало:**
```
ERROR: Спецсимволы в именах: "<исходный_фрагмент>"
PLAN:  Исправить по описанию
```

- `<исходный_фрагмент>` — конкретное имя / фрагмент кода, где найдена проблема.

### 3.3. Для всех правил

**Требование:** для **каждого** правила колонка `ERROR` должна содержать:
1. **Описание проблемы** (как сейчас).
2. **Исходный проблемный фрагмент** в кавычках.

**Формат:**
```
<описание проблемы>: "<исходный_фрагмент>"
```

**Примеры:**
```
Не корректный префикс, пожалуйста переименуйте "Dp"          → PLAN: Переименовать в "v_iDp"
Переменная "fmt24" более нигде не упоминается.              → PLAN: Удалить объявление
Наименование переменной не содержит префикс типа: "P_PARAM" → PLAN: Добавить префикс типа
Обращение к методу должно быть в формате ::[RUNTIME].[STR]: "STR"  → PLAN: Исправить синтаксис
Спецсимволы в именах: "TEST-TBP"                            → PLAN: Исправить по описанию
Database Link: "@dblink_name"                               → PLAN: Исправить по описанию
```

### 3.4. Источник «исходного фрагмента»

**Варианты (KODA выясняет по коду):**
- `issue.original_code` — если уже передаётся из сканера;
- `issue.matched_text` — если есть;
- **вычислить** из `line` + позиции совпадения.

**Если `original_code` недоступен** — использовать `line` из `scan_report_*`:
- взять фрагмент строки по колонке `LINE`;
- выделить **проблемную** часть (по regexp правила).

**Если ни один источник не даёт** исходный фрагмент — **зафиксировать** в отчёте, **не выдумывать**.
