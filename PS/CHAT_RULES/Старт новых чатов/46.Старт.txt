## ГЛАВНАЯ ТЕМА ЧАТА 46 — тестирование флага ИК

Флаг ИК («Исправить код») управляет тем, применяет ли К2 (fixer)
фактические правки к коду, или только помечает найденные проблемы
(якоря-комментарии). Связанные флаги:
- ВТИК — при ИК: вернуть только исправленный код, без пояснений и
  маркеров изменений; все пояснения/изменения — в лог.
- НеАФ — при ИК: не автофиксировать, только логировать (сухой прогон).

Задача чата: проверить фактическое поведение ИК (и его комбинаций с
ВТИК / НеАФ) на сгенерированных тестовых .plp (кнопка ГТ), зафиксировать
расхождения «ожидаемо / фактически», при необходимости — доработать.

## Правила чата 45 (в копилку, применять в чате 46)

- 6al: .ps1 в PS 5.1 с кириллицей и UTF-8 без BOM -> TerminatorExpectedAtEndOfString.
  Решение: ASCII-only или BOM=True, либо .py-скрипт.
  (Для .txt с кириллицей: UTF-8 BOM через [System.IO.File]::WriteAllText —
  проверено в чате 45 на 45.Отчёт.txt.)
- 6al-2: двойной бэкслеш в PS-строках для Python-продолжений -> одинарный.
- 6an: большие логи тестов — в файл (Tee-Object/Start-Transcript),
  в окно — tail.
- 6ao: не копировать в PS «ожидаемый вывод» (CommandNotFoundException).
- 6ap: запуск + проверка одним блоком.
- 6aq (новое, чат 45): git diff на длинных файлах в PS 5.1 может зависать
  на конвейере (TerminatingError: «Конвейерная обработка была остановлена»).
  Решение: сначала перезагрузить PS, затем читать через
  Get-Content | Select-Object -Skip/-First, либо писать в файл.
- 6ar (новое, чат 45): после git diff -U25 по большому файлу полезно
  сделать git show HEAD:<file> | Select-String -Pattern "DS_..." для
  проверки, что фича уже в HEAD, а не только в рабочей копии.
