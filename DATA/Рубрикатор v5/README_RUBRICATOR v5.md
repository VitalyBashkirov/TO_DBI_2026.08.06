## 5.RUBRICATOR_PARSER_SQL v5.json — ДЕТАЛЬНАЯ ИНФОРМАЦИЯ

5.RUBRICATOR_PARSER_SQL v5.json — это файл, содержащий алгоритмический парсер SQL/PLPlus для автоматического преобразования Oracle/PLPlus синтаксиса в ANSI SQL для DBI.

Состав 5.RUBRICATOR_PARSER_SQL v5.json:
| Категория | Количество правил |
|-----------|------------------|
| v53 правила | 27 |
| тдс20240828 правила | 9 |
| тклоик20240828 правила | 9 |
| PlpCheck правила | 42 |
| Итого | 87 |

Структура каждого правила в 5.RUBRICATOR_PARSER_SQL v5.json:
- rule_code — уникальный код правила
- priority — приоритет выполнения (1 - высокий, 2 - средний, 3 - низкий)
- patterns — массив паттернов для преобразования
  - name — уникальное имя паттерна
  - regex — регулярное выражение для поиска
  - description — описание паттерна
  - transform_type — тип преобразования (regex/hybrid/ignore)
  - transform — шаблон замены (для transform_type=regex)
  - algorithmic_hint — подсказка для алгоритмического парсера (для transform_type=hybrid)
  - fallback_instruction — инструкция для AI при невозможности преобразования
  - example_in — пример входного кода
  - example_out — пример выходного кода

## Быстрый старт

Для анализа кода через AI (DeepSeek, KODA и др.):
1. Открыть новый чат с AI-ассистентом
2. Прикрепить 4.RUBRICATOR_PROMPT v5.json
3. Скопировать промпт: "Проанализируй приложенный PLPlus код по рубрикатору из JSON-файла. Найди все проблемы, укажи строки и предложи исправления."
4. Загрузить файлы для анализа

Для автоматического преобразования SQL:
1. Использовать 5.RUBRICATOR_PARSER_SQL v5.json
2. Запустить гибридный парсер (regex + algorithmic)
3. При необходимости использовать fallback AI инструкции
4. Парсер поддерживает 87 правил (включая PlpCheck)

Для поиска проблем в БД (Oracle):
1. Выполнить find_issues v5.sql на целевой БД
2. Получить список проблемных строк кода (301 запрос)
3. Сопоставить с рубрикатором

Для проверки стиля кода (PlpCheck):
1. Запустить find_issues v5.sql с фильтром по PlpCheck правилам
2. Использовать 4.RUBRICATOR_PROMPT v5.json (правила PlpCheck внутри) для AI-анализа
3. Применить автоматические исправления из 5.RUBRICATOR_PARSER_SQL v5.json
