## 1. Цель

Устранить **раздувание** `Всего проблем` в `scan_report_*`: **89.6%** issues даёт **одно** правило `v53.STOR.SPEC_CHARS.п.2.10`.

**Из отчёта DS_062:**
> regex `[^A-Z0-9_#]` матчит **каждый** спецсимвол (до **57** идентичных issues на строку).

**Следствие:** при **634** issues — **только 130** уникальных `(file, line, check)`.

---

## 2. Что менять

| # | Вариант | Что | Риск |
|---|---------|-----|------|
| **A** | Сузить regex | `[^A-Z0-9_#]` → `\b\w*[^A-Z0-9_#]\w*\b` (только **в именах**) | **Средний** — можно **пропустить** спецсимвол **вне** имени |
| **B** | Дедуплицировать в отчёте | `Всего` = строки таблицы, `Уникальных` = `(file,line,check)` | **Низкий** — только **отчёт** |
| **C** | Дедуплицировать в `scanner` | Если issues **идентичны** (строка, check, desc) — **считать за одну** | **Низкий** — только подсчёт |

**Рекомендация:** **B + C** — минимальный риск:
- **B** — в `scan_report_*` `Всего` = **строк таблицы** (уникальных);
- **C** — в сканере дедуплицировать **идентичные** issues (та же строка, check, desc).

**A** — **не рекомендуем**: может **пропустить** реальные проблемы.

## 3. Шаги

### 3.1. Правка B — `scan_report_*` (Всего)

1. Найти формирование `Всего проблем` в `scan_report_*` (см. `DS_FILES.md` → `scanner.py`).
2. Заменить:
   ```
   Всего проблем: <все issues>
   ```
   на:
   ```
   Всего проблем: <уникальных (file,line,check)>
   Уникальных проблем: <уникальных (file,line,check)>  (опционально — оставить)
   ```
3. **Или** — оставить **оба** счётчика, но **уточнить** подписи:
   ```
   Всего issues (с дублями): N
   Уникальных (file,line,check): M
   ```

### 3.2. Правка C — дедупликация в сканере

1. Найти место, где issue **добавляется** в `self.issues`.
2. **Перед добавлением** — проверить, есть ли **идентичная** issue:
   - та же `file`;
   - та же `line`;
   - тот же `check`;
   - та же `description`.
3. Если **есть** — **не добавлять** (инкремент **счётчика**, но **не** новая запись).

**Или** — **группировать** при формировании `scan_report_*`: одинаковые `(file,line,check,desc)` → **одна строка** + счётчик `count`.
