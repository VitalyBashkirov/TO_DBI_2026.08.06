## 3. Детали реализации

### 3.1. D1 — таблица соответствий (2 NAME)

#### 3.1.1. `MATCHING_TYPES`

**Семантика:** соответствие типов в SQL. Пример (из DS_072d_Разведка §7.2): `doc1 varchar2 := '12345'` → `doc1 number := 12345`.

**Сложность:** требуется **словарь типов**. В текущей версии — regex + таблица известных замен.

**Regex (пример):**

```json
{
  "transform_type": "regex",
  "replace_scope": "match",
  "pattern": "(\\w+)\\s+varchar2\\(\\d+\\)\\s*:=\\s*'(\\d+)'",
  "replacement": "\\1 number := \\2",
  "note": "DS_072d D1: литерал-число в varchar2 -> number; словарная замена"
}
Fallback: если случай не из словаря — ignore.

Реализация: таблица соответствий в transform + regex. При неоднозначности — ignore.

3.1.2. CONTROLTABLECOLUMNSTYPE
Семантика: тип колонки ТБП из допустимых. Пример: [CALC_TUN_NESTED] → subtype + colRepsLinksList.

Сложность: словарь допустимых/запрещённых типов.

Regex (пример):

json
{
  "transform_type": "regex",
  "replace_scope": "match",
  "pattern": "\\[(CALC_TUN_NESTED|METHOD|STATES|OBJECT|CLASS_ATTRIBUTES|METHOD_CONTROLS|INTERVAL)\\]",
  "replacement": "subtype ...",
  "note": "DS_072d D1: словарная замена; при неоднозначности — ignore"
}
Fallback: если неизвестно, какой subtype — ignore.

3.2. D2 — regex с контекстом (4 NAME)
3.2.1. HINT_INDEX_ORDER_BY
Семантика: при хинте на индекс обязателен order by.

Regex:

json
{
  "transform_type": "regex",
  "replace_scope": "multiline",
  "pattern": "pragma\\s+hint\\s*\\(\\s*'index[^']*'\\s*\\)\\s*;?\\s*\\n\\s*(for\\s*\\(\\s*select[^)]*)\\)",
  "replacement": "pragma hint('index...');\nfor (select ... order by ...)",
  "note": "DS_072d D2: добавить order by; колонки — из хинта"
}
Сложность: колонки order by — из хинта (парсинг аргумента). Если не удаётся — ignore.

3.2.2. INVALID_INIT
Семантика: %init(ref, 1 параметр) — недопустимо (только 0 или 2).

Regex:

json
{
  "transform_type": "regex",
  "replace_scope": "match",
  "pattern": "(%init)\\((\\w+),\\s*(true|false)\\)",
  "replacement": "\\1(\\2, \\3, ...)",
  "note": "DS_072d D2: 1-параметр %init -> 0 или 2; при неоднозначности — ignore"
}
Fallback: если целевая форма неясна — ignore.

3.2.3. SIZE_RESTRICTION
Семантика: %size(0) = 0 / %size(null) < 1 → %size(1).

Regex:

json
{
  "transform_type": "regex",
  "replace_scope": "match",
  "pattern": "%size\\s*\\(\\s*(0|null)\\s*\\)\\s*([<>=!]+)\\s*(0|1)",
  "replacement": "%size(1) \\2 \\3",
  "note": "DS_072d D2: замена size-модификатора; правила из html (DS_071 §7.2)"
}
Fallback: если нестандартный оператор — ignore.

3.2.4. INDEX_LENGTH
Семантика: UNIQUE_ID; -- STRING_4000 → -- STRING_200.

Сложность: целевой размер — частично семантичен.

Regex:

json
{
  "transform_type": "regex",
  "replace_scope": "match",
  "pattern": "(\\w+);\\s*--\\s*STRING_(\\d+)",
  "replacement": "\\1; -- STRING_200",
  "note": "DS_072d D2: замена размера — при неоднозначности ignore"
}
Fallback: если размер > 2704 байт — ignore (по html PlpCheck).

3.3. D3 — multiline (3 NAME)
Движок готов (DS_072c + DS_073). Требуется добавить transform с replace_scope: "multiline".

3.3.1. VERIFY_TYPE_IN_WITH
Семантика: переопределение размерности строкового в CTE.

Regex (multiline):

json
{
  "transform_type": "regex",
  "replace_scope": "multiline",
  "pattern": "with\\s+recursive\\s+(\\w+)\\(([^)]+)\\)\\s+as\\s*\\(",
  "replacement": "with recursive \\1(\\2) as (",
  "note": "DS_072d D3: переопределение размерности; по контексту — fallback ignore"
}
Fallback: если тип неясен — ignore.

3.3.2. WITHRECURSIVEMODEL
Семантика: иерархия по таблицам технического ядра (запрещена).

Regex (multiline):

json
{
  "transform_type": "regex",
  "replace_scope": "multiline",
  "pattern": "with\\s+recursive[^;]*\\b(classes|methods|criterias|states)\\b",
  "replacement": "...",
  "note": "DS_072d D3: иерархия по модели данных; замена невозможна -> ignore/AI"
}
Fallback: ignore (детектор) — вендор не даёт good-примера.

3.3.3. PARTITION_ALL
Семантика: добавить условие по ключу секционирования.

Regex (multiline):

json
{
  "transform_type": "regex",
  "replace_scope": "multiline",
  "pattern": "select[^;]*from\\s+(\\w+)[^;]*where\\s+(?!.*partition)",
  "replacement": "...",
  "note": "DS_072d D3: ключ секционирования — из модели данных; fallback ignore"
}
Fallback: ignore (ключ секционирования — модель).
