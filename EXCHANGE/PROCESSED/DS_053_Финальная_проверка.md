## Задачи KODA

### 1. Проверить канон `ai_fallback`

**Что проверить:**

- Во всех файлах, где встречается имя флага AI-фолбэка (`scanner.py`, `code_fixer.py`, `gui_app.py`, `rule_engine.py`, `settings.json`, логи), строка должна быть ровно **`ai_fallback`** (нижний регистр, подчёркивание).
- Не должно быть вариантов: `ai_fallbac`, `AI-fallback`, `AI_fallback`, `aiFallback`.

**Команда для проверки (пример):**

```
findstr /S /I /C:"ai_fallbac" F:\TO_DBI\SRC\*.py
findstr /S /I /C:"AI-fallback" F:\TO_DBI\SRC\*.py
findstr /S /I /C:"ai-fallback" F:\TO_DBI\SRC\*.py
```

(или `grep -r` в bash-эквиваленте)

**Что сделать:**

- Если найдены отклонения — исправить на канон `ai_fallback`.
- Если отклонений нет — подтвердить в отчёте.

**Критерий:** во всех исходниках и логах — только `ai_fallback`.

### 2. Путь к `settings.json` и `.gitignore`

**Что проверить:**

- Фактический путь к `settings.json` (где хранится состояние флагов).
- Если файл лежит **внутри репозитория** (`F:\TO_DBI\...`) — проверить, что он в `.gitignore`.
- Если он **не в `.gitignore`** и попадает в `git status` — добавить в `.gitignore` (это точечная правка, разрешена).

**Формат ответа:**

```
Путь settings.json: <...>
В репозитории: да/нет
В .gitignore: да/нет
Действие: <добавлено / не требуется>
```

**Критерий:** `settings.json` не попадает в `git status` (либо он вне репозитория, либо в `.gitignore`).

### 3. Список тестов `temp\test_ds*.py`

**Что предоставить:**

- Полный список файлов `temp\test_ds*.py` (или где они фактически лежат) с номерами DS.
- Явно указать: покрывают ли они диапазон DS_032–DS_052, или фактический диапазон иной (в отчёте KODA фигурировало «DS_011–DS_048»).

**Формат ответа:**

```
Всего тестов: N
Диапазон: DS_0XX–DS_0YY
Отсутствуют в диапазоне DS_032–DS_052: <список номеров, если есть>
```

**Что сделать:**

- Если DS_049–DS_052 отсутствуют в `temp\` — не создавать их (они выполнялись как протоколы, не как тесты). Просто зафиксировать факт.

**Критерий:** ясная картина — какие тесты есть, какой диапазон покрыт.

### 4. Регресс — подтвердить базовую линию

**Что предоставить:**

- Список 6 предсуществующих падений с именами тестов (он уже фигурировал: `ds026`, `ds040`–`ds043`, `ds048`).
- Подтверждение, что это те же 6, что и в DS_053_Уточнение, и в DS_053_Уточнение_2 — без новых.

**Формат ответа:**

```

Имена: test_ds026, test_ds040, test_ds041, test_ds042, test_ds043, test_ds048
Совпадает с DS_053_Уточнение: да
Совпадает с DS_053_Уточнение_2: да

```

**Критерий:** базовая линия стабильна — 31/37, те же 6 падений.
