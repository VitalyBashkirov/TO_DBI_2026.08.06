4. Детали реализации
4.1. Формат записи
По образцу C4/D4 (DS_072c, DS_072d):

json
{
  "code": "PlpCheck.DBI.<NAME>.п.1",
  "transform_type": "ignore",
  "pattern": "<for_search regex из PROMPT>",
  "note": "DS_072e: группа E (нет замены) — детектор без автофикса. <причина>."
}
4.2. note — по категориям
Категория	Пример	Note
План запроса	CARTESIAN_JOIN, FULL_INDEX_SCAN, FULL_TABLE_SCAN	«детектор плана; требует explain в БД»
Условная компиляция	COND_COMPILE_COMMENT, USER_IF_DEF	«условная компиляция — review вручную»
Запрет (inserts)	INSERT_PLSQL, INTERVAL_NOT_SELECT, ROWID, ROWIDIDENTIFIEDTABLE, USESQLCODE	«запрещено в DBI — ручной перенос»
Макросы EXECUTE/PROCESS	MACROEXECUTEPROCESS, MACROEXECUTEPROCESS_COMMENT, MACRO_CALL_EXECUTEPROCESS	«макросы EXECUTE/PROCESS — запрет в DBI»
Savepoint	SAVEPOINT_ROLLBACK_MACRO_PARAM_LENGTH, SAVEPOINT_ROLLBACK_NAME_LENGTH	«длина savepoint — review»
Идентификаторы	NATIVE_ID_OBJ_IDENTIFIER	«NATIVE_ID — ручной перенос»
XML/JSON	SQL_FUNCTION_UNSUPPORTED, RESTRICTIONS_ON_IGNITE_FUNCTIONS	«SQL-функция не поддержана — замены по требованию»
Regex	REGEXP_DIFF_IN_JAVA	«различие Java/PLSQL — нет механической замены»
UDF в фильтре	UDF_IN_FILTER_FORMULA	«UDF в формуле — ручная правка»
Прочие	EMPTY_STRING_IN_CURSOR, FORM_TRANSACT_CONTROL, RESTRICT_REFERENCES_BAD_USE, SELECTANALYTICARGUMENT	«детектор без автофикса»
4.3. fix_instruction в PROMPT (синхронно)
Для каждого NAME — краткое описание причины (детектор без автофикса). Пример:

CARTESIAN_JOIN: «Детектор плана запроса; требует explain в БД — автофикс не применим».

ROWID: «Запрещено в DBI — замена на ID вручную».

INSERT_PLSQL: «Запрет PL/SQL-вставок — удалить вручную».
