## Новые уроки чата 43 (6.6.34, копилка)

### 6ai - close_ds.ps1 внутри Start-Transcript может терять stdout git
Симптом: [OK] commit / [OK] push есть, а разделы [1.1] git status, [4.x] git status, [5/8] git commit, [7.1]-[7.3] пустые.
Причина: git запускается как subprocess; в PS 5.1 stdout может не попасть в транскрипт (п.6x/6y).
Решение: после close_ds.ps1 ВСЕГДА проверять состояние отдельным блоком БЕЗ транскрипта: git log --oneline -3, git status -sb, git branch -vv.

### 6aj - here-string с кириллицей и фигурными скобками в PS 5.1 зависает
Симптом: вставляешь here-string с русским текстом и фигурными скобками — консоль уходит в ожидание и «висит».
Решение (уточнение п.6z): для больших русских текстов — массив PS-строк + [IO.File]::WriteAllLines(path, lines, UTF8Encoding(false)), либо вынести текст в отдельный .py-скрипт и запустить его.

### 6ak - subprocess.run с encoding=utf-8 на Windows падает на кириллице в stdout
Симптом: PytestUnhandledThreadExceptionWarning: UnicodeDecodeError: utf-8 codec can not decode byte 0xc7.
Причина: gen_test_plp.py (и др.) пишет русский текст в stdout в CP866/CP1251, subprocess читает как UTF-8.
Решение: subprocess.run(..., encoding=utf-8, errors=replace) — некорректные байты заменяются, reader-thread не падает.
