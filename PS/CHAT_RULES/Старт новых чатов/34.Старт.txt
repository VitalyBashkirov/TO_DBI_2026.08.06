## НОВЫЕ ПРАВИЛА / УРОКИ ЧАТА 33

### Правило именования чатов

Имя чата = **NN. <краткое_описание>**, где:
- NN — номер чата (двузначный).
- <описание> — 3-7 слов, ключевая задача чата (через ; если несколько).

Пример: «34. K1=скан+зеркало; K2 без повторного скана».
Используется в шапке 34.Старт.txt и в блоке-заголовке чата (копирование одной кнопкой).

### Грабли PS, проявившиеся в чате 33

- Here-string @'...'@ с многострочным текстом и Python-кодом → ParserError
  (PS 5.1). Решение: писать Python-скрипты на диск через .NET WriteAllText,
  не через массив строк PS.
- В массиве PS-строк @(...) одинарные кавычки экранируются удвоением (''),
  а НЕ \'. Backslash внутри '...' ломает парсер PS 5.1.
- Anchor-замены в Python: многострочный anchor ломается на CRLF/LF.
  Решение: однострочные anchor, либо нормализация text.replace("\r\n","\n").
- git add -u на ignored каталог (EXCHANGE/INBOX) → exit=128. Ожидаемо.
- git push через PS 5.1 → NativeCommandError в stderr, exit=0 корректен.
  Ориентир — LASTEXITCODE.
- «Пустой» лог Start-Transcript при вызове внешних процессов (python, git) —
  буферизация. Решение: пайп в Out-Host (§6.6.1, Урок V).
