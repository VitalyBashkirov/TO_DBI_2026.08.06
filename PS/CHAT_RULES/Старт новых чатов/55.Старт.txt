## ПРАВИЛА ВЫВОДА (утверждены в чате 53, уточнение в чате 54)

1. ПЕРВОЙ командой в каждом PS-блоке — кодовая страница и кодировки:
   $OutputEncoding = New-Object System.Text.UTF8Encoding($false)
   [Console]::OutputEncoding = New-Object System.Text.UTF8Encoding($false)
   chcp 65001 | Out-Null
2. КАНОН ЧАТА 54:
   Start-Transcript -Path $log -Force | Out-Null
   ...
   Stop-Transcript | Out-Null
   Write-Host ("=== Полный путь лога: {0} ===" -f $log) -ForegroundColor Green
   (путь лога — последняя строка консоли; Stop-Transcript не "хвостит").
3. $ErrorActionPreference:
   - "Stop" на старте;
   - "Continue" вокруг ВСЕХ git-вызовов (git пишет в stderr;
     при Stop PS 5.1 ловит NativeCommandError и валит скрипт).
4. python-скрипты — через Start-Process:
   Start-Process -FilePath $python -ArgumentList @("-u", $script) `
       -WorkingDirectory $repo `
       -RedirectStandardOutput $pyOut `
       -RedirectStandardError  $pyErr `
       -NoNewWindow -PassThru -Wait
   НЕ использовать `& python -u $script *> file` — PS 5.1 подставляет
   ParameterBinding(Out-File) и дублирует вывод.
   python -c "..." из PS 5.1 КОРЁЖИТ кавычки (см. 54_07b: 'import' parse error).
   НАДЁЖНО: [IO.File]::WriteAllText($tmp, $code, UTF8NoBOM) + python $tmp.
   $py | python - в PS 5.1 нестабилен — не использовать.
   Для тестов/скриптов всегда:
   $env:PYTHONIOENCODING = "utf-8"; $env:PYTHONUTF8 = "1"
5. Кириллица в литералах — через [System.IO.File]::WriteAllText с
   New-Object System.Text.UTF8Encoding($false) (для стартов — можно $true).
   НЕ Set-Content.
6. Commit msg — через UTF8Encoding($false) во временный файл + git commit -F.
7. Test-Path -LiteralPath для путей с $ и кириллицей.
8. Патч файлов — учитывать CRLF: читать/писать io.open(..., newline=""),
   нормализовать \r\n -> \n, писать обратно в исходном формате.
