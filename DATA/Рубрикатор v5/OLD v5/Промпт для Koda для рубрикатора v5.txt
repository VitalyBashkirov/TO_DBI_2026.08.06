## 7. ПРИМЕРЫ ИСПРАВЛЕНИЙ (ОСНОВНЫЕ ПРАВИЛА)

**OUTER JOIN (v50.SQL.OUTERJOIN.п.1.1):** Было: SELECT * FROM t1, t2 WHERE t1.id = t2.id(+) -> Стало: SELECT * FROM t1 LEFT JOIN t2 ON t1.id = t2.id

**ROWNUM (v50.SQL.ROWNUM.п.1.2):** Было: SELECT * FROM t WHERE rownum <= 10 -> Стало: SELECT * FROM t FETCH FIRST 10 ROWS ONLY

**DECODE (v50.SQL.DECODE.п.1.6.1):** Было: SELECT decode(status,1,'A',2,'B','?') FROM t -> Стало: SELECT CASE status WHEN 1 THEN 'A' WHEN 2 THEN 'B' ELSE '?' END FROM t

**CONNECT BY (v50.SQL.CONNECTBY.п.1.8):** Было: SELECT * FROM t CONNECT BY PRIOR id = parent_id START WITH parent_id IS NULL -> Стало: WITH RECURSIVE cte AS (SELECT * FROM t WHERE parent_id IS NULL UNION ALL SELECT t2.* FROM t t2 JOIN cte ON t2.parent_id = cte.id) SELECT * FROM cte

**DATE (v50.STOR.DATE.п.2.2):** Было: v_date DATE; -> Стало: v_date DATE_TIME;

**WHEN OTHERS (v50.PROC.WHENOTHERS.п.3.5):** Было: EXCEPTION WHEN OTHERS THEN NULL; -> Стало: EXCEPTION WHEN OTHERS THEN ROLLBACK; RAISE;

**EMPTY STRING (v50.PROC.EMPTY_STRING.п.3.2):** Было: WHERE name = '' -> Стало: WHERE name IS NULL

**DBMS_CRYPTO (v50.PROC.CRYPTO.п.3.1.2):** Было: dbms_crypto.hash(src, dbms_crypto.hash_md5) -> Стало: ::[PCORE_INTERFACE].[INT_EXT_CALL_001].HSH_B(...)

**UTL_HTTP (v50.PROC.HTTP.п.3.1.6):** Было: utl_http.request(...) -> Стало: ::[RUNTIME].[HTTP_MGR].url_get(...)

## 8. GUI-ФОРМА: НОВЫЙ ФЛАГ

На форме "Адаптация АРМ под DBI (PostgreSQL)" добавить новый флаг:
☐ Добавлять PlpCheck-правила (стиль кода)

**Логика работы флага:**

При включённом флаге (☑) применяются все 16 правил PlpCheck: исправляются префиксы (v_, n_, d_, b_, lr_, lrec_, tb_), исправляется синтаксис (::[CLASS], [ATTR], ::[CLASS].[METHOD]), добавляется размерность VARCHAR2/STRING, SAVEPOINT заменяется на &sp/&rb, удаляется закомментированный код, удаляются неиспользуемые переменные, выносятся повторяющиеся DEFAULT валидации, глобальные переменные заменяются на параметры, функции из EXECUTE/VALIDATE выносятся в основное тело.
