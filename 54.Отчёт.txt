## 5. Уроки чата 54 (для следующих чатов)

1. PS 5.1 + Python 3.12:
   - python -c "..." из PS 5.1 корёжит кавычки (см. 54_07b: 'import' parse error).
   - Надёжно: [IO.File]::WriteAllText($tmp, $code, UTF8NoBOM) + python $tmp.
   - stdout native-команд в PS 5.1 иногда не доходит (54_07a). Надёжно:
     Start-Process -RedirectStandardOutput + [IO.File]::ReadAllText.
2. $py | python - в PS 5.1 нестабилен: не полагаться, использовать файл.
3. .gitignore скрывал SRC/settings.json (строка 14). Для state-файла,
   без которого load_settings не работает, — git add -f оправдан.
4. inspect.getsource(DBIMigrationApp.<fn>) ищет функцию по имени.
   Если вставка попала не в ту функцию (например, --model в _run_ai_cycle,
   а не в _run_fix), тест t5 должен искать в списке кандидатов.
5. Возврат bool из pytest-функции даёт PytestReturnNotNoneWarning и
   PASSED даже при check(...)=False. Честно: assert ok.
6. Windows Terminal largePasteWarning — отдельный ключ в settings.json,
   не в PSReadLine. Применяется после полного перезапуска WT.
7. amend безопасен, если push не было. 2cb9751 -> bc3d0a3 переписан локально.
