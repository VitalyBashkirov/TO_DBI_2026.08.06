Требования к АРМу:

1. Форма с переменными:
   - Каталог исходных: F:\TO_DBI\DATA\patch_WORK\src\
     [V] Сканировать подкаталоги (шаблон: **\*.plp)
     [ ] Только указанный каталог
   - Каталог результатов: F:\TO_DBI\NEW_DATA\patch_WORK_vXXXX (авто-итерация)
     [V] Только откорректированные файлы
     [ ] Все файлы по шаблону
     [V] Сохранять структуру исходных каталогов
   - Логи:
     [V] В разрезе требований
     [V] В разрезе исходного файла
   - Кнопка "Очистить логи"

2. Правила обработки:
   [V] Применять рекомендации (v50/тдс/тклоик) — выбрать ≥1
   [V] Перед изменённой строкой — маркировку
   [V] Следующая строка — закомментированный старый код
   [V] Исправленный код с комментарием (≤60 символов inline)
   [V] Обрабатывать .pck файл для списка объектов

3. Интерфейс:
   - Tooltips на всех кнопках
   - Блокировка кнопок при некорректных предыдущих действиях
   - Индикация прогресса выполнения
