## Уроки чата 21 (в DS_STANDARD.md §6.2.1 и AGENTS.md)

### Урок A: -SimpleMatch не понимает |

- ПЛОХО: Select-String -Pattern 'a|b' -SimpleMatch (ищет буквальную строку "a|b").
- ХОРОШО (regex, без -SimpleMatch): Select-String -Pattern 'a|b'.
- ХОРОШО (два вызова): Select-String -Pattern 'a' -SimpleMatch; Select-String -Pattern 'b' -SimpleMatch.

### Урок B: Select-String находит docstring и сигнатуры

- ПЛОХО: Select-String -Pattern 'bot=True' -SimpleMatch (найдёт docstring L109,
  сигнатуру L108).
- ХОРОШО: Select-String -Pattern 'bot=True)' -SimpleMatch (только вызовы).

### Урок C: [System.IO.File]::ReadAllBytes/WriteAllText — только абсолютные пути

- ПЛОХО: $p = 'EXCHANGE\INBOX\file.md'; ReadAllBytes($p) → DirectoryNotFoundException.
- ХОРОШО: $p = (Resolve-Path -LiteralPath 'EXCHANGE\INBOX\file.md').Path; ReadAllBytes($p).

### Урок D: вложенные ``` ломают разметку при Text Copy Download

- При копировании .md-задания через Text Copy Download вложенные блоки кода
  ломают разметку.
- Решение: плоский формат — отступы (4 пробела) вместо блоков кода.
- Зафиксировано в DS_STANDARD.md §3.2.

### Урок E: INBOX-гигиена при ручном выполнении DS

- При ручном выполнении DS (без KODA) — файл задания из INBOX ОБЯЗАТЕЛЬНО
  удалять (или перемещать в PROCESSED).
- Причина: KODA ориентируется на имя INBOX-файла (урок чата 19).
- Проверка: Get-ChildItem EXCHANGE\INBOX → пусто.
- Замечание: tools\close_ds.ps1 v2 создаёт PROCESSED/OUTBOX с нуля,
  но НЕ чистит INBOX — надо вручную.
- Зафиксировано в AGENTS.md L624.

### Урок F: Простые DS — без KODA

- Если DS — простое одношаговое действие (правка конфига, удаление файла,
  замена строки) — выполняется вручную PowerShell, без KODA.
- Порядок:
  1. DeepSeek формирует PS-блок.
  2. Vitaly запускает в PS.
  3. DeepSeek формирует файлы задания/отчёта постфактум (после выполнения).
  4. Запись в bot.log, коммит, push.
- KODA не запускается.
- Последняя строка PS-блока:
  Write-Host "В KODA DS_XXX_описание.md запускать не нужно. Задачу закроем в PowerShell"
- Зафиксировано в AGENTS.md L610.

### Урок G (новый, чат 21): -Filter не поддерживает regex-классы

- ПЛОХО: Get-ChildItem -Filter 'DS_12[1-5]*' → не работает (Filter не понимает [1-5]).
- ХОРОШО: Get-ChildItem -Filter 'DS_12*' → работает (wildcard).
- Либо: Get-ChildItem | Where-Object { $_.Name -match '^DS_12[1-5]' }.
- КАНДИДАТ В DS_126 (или расширение §6.2.1).
