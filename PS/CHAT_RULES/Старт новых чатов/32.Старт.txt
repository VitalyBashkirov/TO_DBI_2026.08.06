## НОВЫЕ ПРАВИЛА / УРОКИ ЧАТА 31

Зафиксированы в DS_STANDARD.md §6.6.10–§6.6.17.

### §6.6.10 — Урок LLL: активный транскрипт блокирует N7

Start-Transcript в PS 5.1 держит файл открытым на запись до Stop-Transcript
или закрытия окна. N7-очистка падает на активном логе с IOException.

Решение (N7 v2): очищать PS с явным исключением активного лога
(Where-Object по имени) + try/catch для остальных занятых.

### §6.6.11 — Урок MMM: Tkinter after() в pytest → TclError

root.after(ms, callback) регистрирует pending команду в Tcl.
После root.destroy() Tcl вызывает уничтоженную команду → TclError.

Решение (conftest.py v3):
- _cancel_all_after(root) — отменить pending after перед destroy.
- monkeypatch _poll_ai_out (самоперезапускающийся таймер) → noop.

### §6.6.12 — Урок NNN: кириллица в PS-путях

Test-Path в PS 5.1 может врать для папок с кириллицей.
Проверять через Python Path.exists() / iterdir().

Инцидент: «Рубрикатор v5» (не «Рубикатор»).

### §6.6.13 — Урок OOO: trace_add('write') side-effects

StringVar.trace_add('write', callback) вызывает callback на каждое .set().
В gui_app на source_dir_var висят _on_source_dir_changed,
_update_dir_indicators — читают диск, логируют.

### §6.6.14 — Урок PPP: pytest.ini --capture=no и print

При --capture=no stdout не захватывается. print из legacy-модулей
виден многократно (по разу на тест). Безвредно, шумно.

### §6.6.15 — Урок QQQ: Get-Content в PS 5.1 не UTF-8

Get-Content в PS 5.1 по умолчанию читает как cp1251/cp866.
UTF-8 файлы показываются кракозябрами. Проверять через Python.

### §6.6.16 — Урок RRR/SSS: $ErrorActionPreference между блоками

$ErrorActionPreference = 'Stop' — переменная сессии, сохраняется
между блоками. Если блок 1 поставил Stop — блок 2 упадёт на первом
stderr (git warning LF/CRLF → NativeCommandError).

Решение: явно сбрасывать $ErrorActionPreference = 'Continue' в начале
каждого блока с внешними процессами. Ориентир — $LASTEXITCODE.

### §6.6.17 — Урок TTT: here-string + backticks

Вставка многострочного блока с @'...'@ + Markdown-backticks внутри
ломает PS 5.1 — блок зависает в режиме >>.

Решение: если текст содержит backticks — писать через Python, не PS.
