# Регламент коммитов

## msgfile
UTF-8 **БЕЗ BOM**:
```powershell
$enc = New-Object System.Text.UTF8Encoding($false)
[System.IO.File]::WriteAllText($msgFile, ($msgLines -join "`r`n"), $enc)
```
С `$true` BOM попадает в первую строку сообщения коммита.

## Коммит
```powershell
& git add -- $targetRel
& git commit -F $msgFile
& git push origin feature/dockerization
```
`-F <msgfile>`, не `-m` (многострочный `-m` в PS 5.1 ломается).

## Два представления пути
- `$targetRepo = 'SRC/tests/...'` — от **корня репо**, для `git status`, `git diff`.
- `$targetRel = 'tests/...'` — от **`$repo`**, для `git add --`, `git checkout --`, `Test-Path`, `Join-Path`.
Не путать (см. 59_06: `Join-Path $repo 'SRC/...'` → двойной SRC; 59_15: `git checkout -- 'SRC/settings.json'` из `$repo` → не найден).

## Что не коммитить
- `EXCHANGE/*` — фоновые грязные файлы.
- `*.ds183bak`, `*.tmp`, `__pycache__/`, `*.pyc`.

## Проверка после push
`git status -sb` — `## feature/dockerization...origin/feature/dockerization` **без** `[ahead N]`.
`git log -1 --oneline` — новый хеш.
## 61_1. Корень репо (чат 61)
Корень git-репо — `F:\TO_DBI`, не `F:\TO_DBI\SRC`. `.git` в `F:\TO_DBI`.
`$root = 'F:\TO_DBI'`, `$repo = 'F:\TO_DBI\SRC'` (подкаталог).
- `$targetRepo = 'SRC/tests/...'` — от `$root`, для `git status` / `git diff`.
- `$targetRel  = 'SRC/tests/...'` — от `$root`, для `git -C $root add --`, `git -C $root checkout --`.
Не путать с прежним `$targetRel = 'tests/...'` (это было бы от `$repo`).
