### §6.6.29 — Уроки чата 37: PS here-string + Python

1. Никогда не использовать обратный слэш перед кавычкой в here-string.
2. Не использовать тройные кавычки внутри here-string.
3. f-строка с одинарными кавычками внутри.
4. Или: писать Python-скрипт-правку через Path.write_text() — без here-string.
5. После записи — ast.parse.
6. .log через Get-Content в PS 5.1 — только Python с utf-8.

### §6.6.30 — _split_declare: внешние begin/end/declare

Внешние begin/end убирать через re.sub, нормализовать отступы (min indent),
снимать префикс declare через re.sub (r"^\s*declare\s+").

### §6.6.31 — pytest Test* class: __test__ = False

Если в модуле есть класс Test* (TestGeneratorV2), pytest его соберёт и
выдаст PytestCollectionWarning. Пометка __test__ = False в классе.
