## 6. Новые задачи (очередь)

### DS_058 — GUI не должен менять `1.RUBRICATOR_FILES v5.md`
**Баг:** при запуске GUI и переключении чекбокса рубрикатора — файл `DATA/Рубрикатор v5/1.RUBRICATOR_FILES v5.md` **изменяется** (признак `±` → `+`). Это меняет семантику обработки v53. GUI должен хранить состояние в `settings.json`, а не в рубрикаторе.

### DS_056 — `_is_in_comment_or_string`
Улучшение: многострочные комментарии, `&debug(...)`.

### DS_057 — Рубрикаторы в GUI + тултипы
Отдельные чекбоксы для рубрикаторов (v53 / тдс / тклоик / PlpCheck), фильтрация в RuleEngine по источнику. Тултипы всем кнопкам.

### DS_059 — PLAN в `scan_report_*` — конкретика
Сейчас в колонке PLAN — «Исправить по описанию». Нужно — конкретное действие (как в `scan_VVxVVx_*`).

### DS_060 — RuleEngine — расширить на `plpcheck.*`
Сейчас RuleEngine загружает только `5.RUBRICATOR_PARSER_SQL v5.json` (75 правил `v53.*`). Нужно — добавить `plpcheck.*`.

### DS_061 — Прогноз (`scan_VVxVVx_*`) для `plpcheck.*`
Сейчас прогноз работает только для `v53.*`. Для `plpcheck.*` — PLAN пустой.

### DS_062 — Дубли 323 vs 52
Сканер показывает `Всего проблем: 323, Уникальных: 52`. Разобраться, почему дубли.

## 7. Правила автора DS

1. Формат файла: `DS_XXX_<КраткоеОписание>.md`
2. Соблюдать протоколы DS_048/049/050/052
3. Кодировки: `bot.log` — UTF-8 без BOM, OUTBOX — CR LF, Python — `utf-8`
4. Не ломать тесты DS_032–DS_055
5. Коммит — только по команде `GIT`, push — по команде `PUSH`
