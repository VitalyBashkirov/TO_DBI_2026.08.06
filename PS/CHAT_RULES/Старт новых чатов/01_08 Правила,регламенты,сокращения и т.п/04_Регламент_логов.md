# Регламент логов PS

## Путь
Только `F:\TO_DBI\PS\`. `%TEMP%` и другие каталоги — запрещены.

## Имя
`<hostTag>_<чат>_<номер>_<action>.log`.
Пример: `LG_59_16_rules_init.log`.

## Start-Transcript
- БЕЗ `-Encoding` (PS 5.1 не принимает).
- Первая строка после Start-Transcript — `Write-Host "hostTag=... host=..."`.

## Что попадает в транскрипт
Только host-вывод: `Write-Host`, `Write-Output` (строки), `print` из python, `echo`.
Объектный конвейер (`Get-Item | Select-Object`, `Get-Content` без `| Out-String`) — **не гарантированно**.
Для проверок — `... | Out-String | Write-Host` или отдельный .txt + `Get-Content ... | Out-String | Write-Host`.

## Pytest-выхлоп
Не через `Tee-Object` в транскрипт (ненадёжно). Всегда:
```powershell
& $python -m pytest ... 2>&1 | Out-File -FilePath $out -Encoding utf8
Get-Content $out | Out-String | Write-Host
```

## После работы
Удалить все файлы нулевой длины из `F:\TO_DBI\PS\`.

## Финал скрипта
`Write-Host "LOG: $log" -ForegroundColor Green` (без паузы — см. правило 10).
