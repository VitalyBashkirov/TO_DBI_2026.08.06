# Матрица флагов (чат 46)

МПК / ВТИК / НеАФ → поведение К2.

Обозначения: Я = якоря-комментарии; П = фактические правки; В = возврат кода.

| МПК | ВТИК | НеАФ | Я | П | В |
|-----|------|------|---|---|---|
| off | off  | off  | нет | да  | полный файл |
| on  | off  | off  | да  | да  | полный файл с якорями |
| on  | off  | on   | да  | нет | полный файл с якорями; правки только в лог (сухой прогон) |
| on  | on   | off  | нет | да  | только исправленный код, без якорей (ВТИК перекрывает МПК) |
| off | on   | off  | нет | да  | только исправленный код |
| off | off  | on   | нет | нет | без изменений, только лог |

Приоритет:
- **ВТИК=on** → МПК отменяется.
- **НеАФ=on** → применение правок отменяется.

Примечание: текущее поведение `fix_only_found=on` (применять+якоря) соответствует строке `on / off / off`.
