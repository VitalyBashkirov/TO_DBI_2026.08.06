- `code_fixer_old.py` — **устаревшая** версия (предположительно, не используется).

## Задачи KODA

### Задача A — Проверить, что `code_fixer_old.py` не используется

**Команды:**

```bash
ls -la SRC/fixer/code_fixer_old.py
grep -rn "code_fixer_old" SRC/ temp/ EXCHANGE/ 2>/dev/null
grep -rn "from.*code_fixer_old\|import.*code_fixer_old" SRC/ temp/ 2>/dev/null
grep -rn "code_fixer_old" temp/test_ds*.py 2>/dev/null
```

**Критерий:** ни одного упоминания (кроме самого файла).

**Если упоминания есть** — СТОП, сообщить в отчёте. Не удалять, пока не уберём зависимости (отдельная задача).

### Задача B — Удалить файл

**Только если задача A дала «0 упоминаний»:**

```bash

```

**Критерий:** файл удалён, `git status` показывает `deleted: SRC/fixer/code_fixer_old.py`.
