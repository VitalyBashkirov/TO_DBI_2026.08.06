## Открытый вопрос (продолжение чата 48)

Правило plpcheck.SUBOPTIMAL_QUERY_WROWNUM не находится в файле
PSH_ED_PRC_SCHM.plp (строки 112-118: `for (...) loop ... exit; end loop;`).

Причина: в scanner.py (строки 671-693) регулярные выражения для поиска
(regex_patterns.for_search) применяются БЕЗ флага re.DOTALL, поэтому
многострочные паттерны (например, `for\s*\(.*select.*\)\s+loop.*\bexit\b`)
не срабатывают.

  ИКА — Исходный каталог (источник .plp)
  КР  — Каталог результатов (приёмник)

BOX «3. Опции сканирования и исправления. Логирование» — флаги:
  МПК       — «Маркировка правок»: вставляет якоря-комментарии
  Применять — применять фактические правки (бывш. fix_only_found)
  ВТИК      — «Верни только исправленный код без пояснений и маркеров изменений.
              Все пояснения, изменения, удаления журналируй» (= clean_output)
  НеАФ      — ignore (не автофиксить, только лог)

Выпадающий список уровней логирования:
  УЛ  — Уровень логирования
  УЛМ — Минимальный
  УЛП — Подробный

Приоритет флагов:
  ВТИК=on  -> МПК отменяется (якоря не ставятся); вернуть только исправленный код.
  НеАФ=on  -> правки НЕ применяются (сухой прогон); МПК может ставить якоря.

Формат якоря (МПК):
  -- YYYY.MM.DD HH:MI|<Правило>[xN][[Ai]]|Строка NN
  -- YYYY.MM.DD HH:MI|<Правило>[xN][[Ai]]|Строки NN-NN
  [xN]   — только если N>1 (число срабатываний).
  [[Ai]] — только если для правки использовался Ai.

### Правило F (DS_125)
Все DS — вручную PowerShell. Автор DS НЕ создаёт файлы сам,
а выдаёт ГОТОВЫЙ PS-блок. Пользователь запускает его в PS.

### Правило 155 (DS_151)
ВСЕ PS-блоки (в т.ч. read-only) логируются через Start-Transcript
в F:\TO_DBI\PS\chatNN_MM_<name>.log.

### Правило 6at
Start-Transcript + host-вывод (Write-Host, print).
Объектный конвейер через Out-String | Write-Host.
Не использовать Format-Table (не попадает в транскрипт).

### Правило 6at-1
Кириллица в многострочных литералах PS 5.1 — через
[System.IO.File]::WriteAllText с New-Object System.Text.UTF8Encoding($true).
НЕ использовать Set-Content -Encoding UTF8 (не BOM).

### Правило 6at-2
Проверка записи файлов сразу после записи:
Get-Item $path | Out-String | Write-Host
Get-Content $path -Encoding UTF8 -TotalCount 5 | Out-String | Write-Host

### Правило терминального оператора (PS 5.1)
В PS 5.1 нет тернарного ?: — использовать if () {} else {}.
Пример: 
  $status = if ($x) { "есть" } else { "отсутствует" }
  Write-Host ("Статус: {0}" -f $status)
