# Задача: Разработать АРМ "Адаптация под DBI" v.03

## Контекст
Миграция АБС "ЦФТ-Банк" с Oracle (Платформа 1) на PostgreSQL (Платформа 2 MCA DBI).

## Структура проекта (X:\TO_DBI\)
- DATA\          # Исходные данные (только чтение)
  - patch_*/      # Локальный функционал для миграции (имя с префиксом patch_)
  - patch_*.pck   # Перечень объектов для экспорта/импорта
  - CFT Platform IDE Documentation\  # Документация
  - ПОМПТы\       # Промпты версий
- SRC\            # Разрабатываемый код АРМа
  - analyzer\, fixer\, utils\, AI_DOCS\
- NEW_DATA\       # Результат миграции
  - logs\

## Инструменты
Python 3.12+, Tkinter, VS Code, PowerShell, CFT Platform IDE (Ctrl+D,A)

## Требования к АРМу (Tkinter .exe)

### 1. Параметры на форме (с сохранением в SRC\config.json)
| Параметр | Значение по умолчанию | Примечание |
|----------|----------------------|------------|
| Корневой путь | X:\TO_DBI\ | |
| Каталог исходных данных | DATA\patch_* | Только чтение |
| Шаблон файлов | *.pck или *.sql | |
| Сканировать подкаталоги | Да ☑ | |
| Каталог результатов | NEW_DATA\ | |
| Сохранять только изменённые файлы | Да ☑ | |
| Копировать структуру исходников | Нет ☐ | |
| Логировать по требованиям | Да ☑ | |
| Логировать по файлам | Да ☑ | |

**Обязательный выбор:** минимум один документ из:
- Рекомендации по адаптации PLPlus для DBI
- Требования совместимости с DBI  
- Требования к локальным объектам (доп. регламенты)

- **Анализ** — поиск проблемных конструкций в PL+ коде
- **Исправление** — автоматическое с маркировкой
