### 2.3. Логика активации 1→2→3

**Триггеры пересчёта:**
- при загрузке GUI (после `_create_widgets`);
- при изменении в боксе 1: ИК, КР, Шаблон, ☑ Рекурсивно;
- при изменении в боксе 2: любой чекбокс «Выбрано»;
- при изменении в боксе 3: любые опции.

**Условия:**

| Кнопка | Условие |
|--------|---------|
| **«1. Сканировать»** | ИК ≠ пусто И КР ≠ пусто И Шаблон ≠ пусто И хотя бы один рубикатор выбран |
| **«2. Исправить код»** | Скан завершён И в КР (или подкаталогах) есть файлы по Шаблону |
| **«3. В Ai»** | Фикс завершён И в `EXCHANGE\AI_IN` есть `AI_REQUEST_*.md` |

**В любой момент только одна из 1/2/3 активна и жирная. Остальные — disabled, обычная.**

Метод: `widget.config(state=NORMAL/DISABLED)` + `widget.config(font=bold/regular)`.

### 2.5. Размер окна + центрирование

Заменить `self.root.geometry("1090x650")` (стр. 184) на:

```python
W, H = 1600, 900
sw = self.root.winfo_screenwidth()
sh = self.root.winfo_screenheight()
if sw < W or sh < H:
    W, H = sw, sh  # во весь экран
x = (sw - W) // 2
y = (sh - H) // 2
self.root.geometry(f"{W}x{H}+{x}+{y}")

2.6. Пересчёт пропорций layout (вместо скролла)
Цель: при 1600×900 все элементы + кнопки [...] + скроллбары видны.

2.6.1. Сузить поля ИК/КР → кнопки [...] видимы

Поля Исходный каталог, Каталог результатов — уменьшить ширину
(например, width=60 вместо width=80, или pack(fill=X, expand=False)).

Кнопки [...] — прижать вплотную к полям, оставить видимыми.

Проверить, что обе кнопки [...] влезают в 1600.

2.6.2. Таблица рубикатора — скроллбары видны

Колонка Полное имя файла — stretch=False (не растягивается).

Вертикальный + горизонтальный скроллбары — должны быть видны (не за краем).

Проверить ширину таблицы: сумма колонок + скроллбары ≤ ширина бокса 2.

2.6.3. Бокс 3: сдвинуть влево правую группу

Элементы:

Уровень логирования: [Минимальный ▼]

Топ-файлов, мин. файлов: [10]

☑ Архивировать результат

Действие: сдвинуть влево внутри бокса 3 — чтобы не прижимались к правому краю.
Метод: pack(side=LEFT, padx=...) вместо side=RIGHT, или grid с columnconfigure.

2.6.4. «Журнал выполнения» — верт. скроллбар виден

journal_frame — сузить так, чтобы верт. скроллбар Text-лога был виден.

Проверить ширину Text + скроллбар ≤ ширина окна.

2.6.5. Если после сужения элементы не влезают — СТОП, вопрос автору.

Entry (ИК, КР, Шаблон, Топ-файлов): Ctrl+C / Ctrl+V.

Text (лог «Журнала выполнения»): Ctrl+C.

Если не работает — зафиксировать в отчёте, не чинить.
