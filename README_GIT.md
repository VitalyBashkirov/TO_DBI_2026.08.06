# Инструкция по сохранению проекта в Git

## 1. Установка Git

Скачайте и установите Git с официального сайта:
https://git-scm.com/download/win

## 2. Инициализация репозитория

Откройте PowerShell и выполните:

`powershell
cd F:\TO_DBI
git init
git add .
git commit -m "АРМ Адаптация под DBI v05 - Полная версия с Рубрикатором"
`

## 3. Проверка

`powershell
git status
git log --oneline
`
