## ✅ Внесённые изменения

### 1. Замена формата ссылок на документацию

**Было (v01):**
```
Стр.X,П.Y  (Страница, Абзац)
```

**Стало (v02):**
```
строки с XXXX по YYYY  (Диапазон строк в txt-файле)
```

**Причина:**
- Документация переведена из `.docx` в `.txt` формат
- Страницы в txt не имеют смысла
- Строки точнее указывают на нужные фрагменты

---

### 2. Обновлённые поля в rubricator_markers.json

| Поле v01 | Поле v02 | Изменение |
|----------|----------|-----------|
| `page_paragraph` | `line_range` | Переименовано |
| `Стр.X,П.Y` | `строки с XXXX по YYYY` | Новый формат |
| `updated: 2026-04-13` | `updated: 2026-04-15` | Обновление даты |
| `version: v01` | `version: v02` | Версия рубрикатора |

## 🔧 Инструкция по заполнению

### 1. Открыть документацию

```
F:\TO_DBI\DATA\CFT Platform IDE Documentation\
Рекомендации по адаптации кода на PLPlus для работы с DBI приложением v50.txt
```

### 2. Найти нужный раздел

Искать по названию пункта (например, "3.26. NativeID")

### 3. Записать диапазон строк

Например: `строки с 32 по 48`

### 4. Обновить рубрикатор

Открыть `rubricator_markers.json` или `.csv` и вписать диапазон в поле `line_range`

### 5. Сохранить

```bash
# В Python
python rubricator_loader.py
```
