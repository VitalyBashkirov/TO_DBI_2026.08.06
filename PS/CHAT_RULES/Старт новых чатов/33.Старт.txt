### §6.6.18 — Урок UUU: N7 v6 — очистка PS\ с сохранением PS\persist\

Эволюция N7: v2 (файлы в корне) -> v4 (только *.log) -> v5 (полная
очистка) -> v6 (persist). Итог: N7 v6 чистит PS\ рекурсивно, кроме
активного лога и PS\persist\.

Шаблон N7 v6:

    $logName    = 'DS_XXX_stepN_...log'
    $logPath    = Join-Path 'F:\TO_DBI\PS' $logName
    $persistDir = 'F:\TO_DBI\PS\persist'

    if (-not (Test-Path $persistDir)) {
        New-Item -ItemType Directory -Path $persistDir -Force | Out-Null
    }

    Get-ChildItem 'F:\TO_DBI\PS' -Force -ErrorAction SilentlyContinue |
        Where-Object {
            $_.Name -ne $logName -and
            $_.FullName -ne $persistDir
        } |
        ForEach-Object {
            try { Remove-Item $_.FullName -Force -Recurse -ErrorAction Stop } catch {}
        }

Рабочие скрипты между блоками — в PS\persist\. Одноразовые — в
корень PS\. Рабочие утилиты проекта — в tools\.

### §6.6.19 — Урок VVV: backslash в f-string {...} -> SyntaxError

Python < 3.12 не позволяет backslash внутри {...} f-string.
f"{raw.count(b'\r\n')}" падает с SyntaxError до выполнения.

Решение: вычислять значение с backslash-литералом в отдельной
переменной до f-string. Или %-форматирование.

Инцидент: DS_143 — трижды (шаг A, шаг E, проверка задания).

### §6.6.20 — Урок WWW: Add-Content -Encoding UTF8 в PS 5.1 = BOM

Add-Content -Encoding UTF8 в PS 5.1 пишет UTF-8 с BOM. Для файла
в UTF-8 без BOM это ломает формат.

Решение: Python (open(path, 'a', encoding='utf-8')) или .NET
[System.IO.File]::AppendAllText с UTF8Encoding($false).

Инцидент: DS_143/DS_144 закрытие — bot.log через Add-Content.

### §6.6.21 — Урок XXX: Python print с кириллицей — кракозябры в Start-Transcript

Python print с русским текстом в Start-Transcript PS 5.1 попадает
как кракозябры (кодировка транскрипта cp1251/cp866, вывод UTF-8).
LASTEXITCODE при этом корректен.

Решение: критичные проверки — ASCII-only (%-форматирование без
кириллицы). Результаты читать через Get-Content -Encoding UTF8
или через файл-посредник.

Инцидент: DS_143 шаг C.1, DS_144 шаг D.6.

### §6.6.22 — Урок YYY: write_text(newline='\n') нормализует весь файл

Path.write_text(text, newline='\n') применяет newline-преобразование
ко всему тексту. Если файл был смешанный (часть CRLF, часть LF),
после записи весь файл станет LF.

Безопасно для Git — Git нормализует .py до LF при коммите, diff
чистый. Но на диске файл меняется больше, чем «на N строк».

Инцидент: DS_143 шаг C.1 — gui_app.py уменьшился с 355148 B до
349231 B при git diff +22/-9.
