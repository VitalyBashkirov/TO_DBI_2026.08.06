## 3. Детали реализации

### 3.1. Этап 1 — C1: `OUTER_JOIN`

**Семантика:** `where p.[X] = (true)` → scalar subquery / ANSI-join.

**Regex:**

```json
{
  "transform_type": "regex",
  "replace_scope": "match",
  "pattern": "(\\w+\\.\\[[A-Z_]+\\])\\s*=\\s*\\(\\s*true\\s*\\)",
  "replacement": "::[{object_type}](\\1)",
  "note": "DS_072c C1: (true) -> scalar subquery по объекту; тип объекта — из контекста (fallback: ignore при неопределённости)"
}
Fallback: если тип объекта неизвестен — ignore (детектор).

3.2. Этап 2 — движок replace_scope: "multiline"
Проблема (DS_072c_Разведка §7.5): apply_fix_ex работает построчно — не может:

вставить строку в блок (close, commit, &sp(SET));

переставить подзапрос;

переписать блок (view … instead of …).

Требование: добавить поддержку replace_scope: "multiline" в:

SRC\rule_engine.py — apply_fix_ex;

SRC\analyzer\sql_parser.py — вызов re.sub с флагом re.MULTILINE + re.DOTALL.

API: transform.context_before / transform.context_after — сколько строк до/после матча захватить.

Пример:

json
{
  "transform_type": "regex",
  "replace_scope": "multiline",
  "context_before": 2,
  "context_after": 3,
  "pattern": "...",
  "replacement": "..."
}
Тесты: temp\test_ds072c_driver.py — синтетика (многострочный блок).

3.3. Этап 3 — C2: 7 правил
После движка реализовать transform для:

NAME	Замена (было → стало)
NOT_CLOSED_CURSOR	Вставить close() в begin…end
NOT_CLOSED_FILE	Вставить f_close(file) в begin…end
NOT_HANDLED_CURSOR_EXCEPTIONS	Вставить close и в тело, и в exception
OBLIGATORY_IN_OTHERS	Вставить &sp(SET) / &rb(SET) + raise
SUBOPTIMAL_UNSELECTED_COL_USAGE	Добавить [B] в select-list курсора
FETCH_OVER_SUBQUERY	Переставить: fetch после inline-подзапроса
CRIT_EXT_IN_OLD_FORMAT	Переписать view X_EXT instead of X { type main is … }
Каждое — по образцу эталонов (BAD_PREFIX, CODE_IN_COMMENT, WRONG_METHOD_SYNTAX).

Fallback: где замена неоднозначна — ignore.

3.4. Этап 4 — C3: 6 AI-правил
Зафиксировать как transform_type: "ignore" + note:

NAME	Почему AI
ACCESS_STATIC	Требуется объявление doc ref — имя семантическое

Формат note: «AI-фолбэк через needs_ai_fix (DS_054); hybrid не поддерживается _pattern_bucket (DS_072a_Уточнение_B)».
