### Правило N6 (НОВОЕ, чат 24): AppendAllLines в PS 5.1 нет

В .NET Framework (PS 5.1) НЕТ [System.IO.File]::AppendAllLines.
Есть: AppendAllText (одна строка), WriteAllLines (перезапись),
WriteAllText (перезапись).
Для ДОБАВЛЕНИЯ массива строк: ReadAllLines -> $existing + $new ->
WriteAllLines. См. урок Q.

## Уроки чата 24 (в DS_STANDARD.md §6.2.1 при следующей правке)

### Урок N: .Replace заменяет ВСЕ вхождения подстроки

.Replace('"""', 'r"""') на однострочном docstring """...""" заменит
И открывающую, И закрывающую кавычки. Получится r"""...r""" —
валидный синтаксис, но семантически сломанный docstring (.r в конце).
Решение: ограничить контекст (.Replace('    """', '    r"""') — с
отступом), либо править только первое вхождение.

### Урок O: -ForegroundColor требует Write-Host

В PowerShell выражение "текст" -ForegroundColor Red НЕ работает в
блоке else { } (строка — не команда). Только Write-Host "текст"
-ForegroundColor Red. Ошибка проявляется на этапе парсинга, до выполнения.

### Урок P: длинные here-string с Python-кодом + backtick — дробить

PS-блок с @'...'@, содержащий тройные backtick (Markdown) и кириллицу,
может «зависнуть» при вставке — PowerShell не видит закрывающий @'@.
Решение: не использовать тройные backtick внутри here-string;
формировать файлы через массив строк @( 'строка1', 'строка2', ... )
и WriteAllLines. Дробить большие блоки на части.

### Урок Q: AppendAllLines в PS 5.1 отсутствует

[System.IO.File]::AppendAllLines — метод .NET Core/5+. В PS 5.1
(.NET Framework 4.x) его НЕТ, ошибка MethodCountCouldNotFindBest.
Для добавления массива строк к файлу:
  $existing = [System.IO.File]::ReadAllLines($path, $enc)
  $all = $existing + $newLines
  [System.IO.File]::WriteAllLines($path, $all, $enc)
