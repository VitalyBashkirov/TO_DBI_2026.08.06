## Описание

Добавлены команды `GIT` и `PUSH` в AGENTS.md.

### Команда GIT

- Выполняет `git commit` с сообщением `GIT_YYYYMMDD_HHMM Выполнено`.
- **НЕ** делает push по команде GIT.
- Если изменений нет — пишет в bot.log `GIT_YYYYMMDD_HHMM Изменений нет.`, коммит не создаёт.
- Использует `git add -A` (НЕ `git add .`).
- Не коммитит файлы из `.gitignore` (EXCHANGE, PATCH_IN, PATCH_OUT, temp, logs, DATA/... и т. д.).

### Команда PUSH

- Выполняет `git pull --rebase origin feature/dockerization`.
- Затем `git push origin feature/dockerization`.
- **НЕ** делает commit по команде PUSH (только pull --rebase + push).
- Если всё up-to-date — пишет в bot.log `GIT_YYYYMMDD_HHMM Push. Отправлено в origin/feature/dockerization.`, exit 0.
- Не делает `git push --force` без явной команды пользователя.

### Формат меток

`GIT_YYYYMMDD_HHMM` — где `YYYYMMDD` — дата, `HHMM` — время (часы и минуты).

### Формат записей bot.log

`[ДД.ММ.ГГГГ ЧЧ:ММ:СС] GIT_YYYYMMDD_HHMM <статус>. <описание>.`

- UTF-8 без BOM.
- Кириллица.
- Разделитель записей — перевод строки.
